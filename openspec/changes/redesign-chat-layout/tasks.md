# Tasks

> 应用顺序：本变更的登录相关 delta 以 `refine-login-panel` 归档后的主 spec 为基线，需先完成并归档 `refine-login-panel`（其 5.4 待人工确认），再开始本变更。

## 1. 主题令牌与动画参数

- [x] 1.1 在 `theme.Palette` 增加 `BubbleSelf`、`BubbleOther`、`Input`、`InputFocus` 四个令牌，`ink` 与 `paper` 各定一组；验证两个气泡色互不相同、各自与消息区背景有对比，且 `Input` 与 `InputFocus` 互不相同、都不同于 `Surface`
- [x] 1.2 `quantize256` 与 `monochrome` 覆盖新令牌：256 色下两个气泡色仍是两种颜色，单色下映射到不同灰度；验证降级后断言仍成立（对应 spec「降级后边框仍可区分」）
- [x] 1.3 在 `pkg/tui/anim` 增加列表选中用的 `ListShimmer`（比 `ButtonShimmer` 更窄更慢）；验证它与前两者是独立的值、光带中心线性行进、两端熄灭
- [x] 1.4 补充令牌与动画参数的单元测试，并更新 `docs/client.md` 里关于主题的说明，验证文档里的令牌名与代码一致

## 2. 表单输入框（登录、注册、找回密码、提示）

- [x] 2.1 改造 `fieldBox`：无论聚焦与否都先用输入背景令牌填满整个输入宽度，再写文字；聚焦用 `InputFocus`、未聚焦用 `Input`；验证用户名只有 2 个字符时背景仍占满、与密码行左右边界对齐
- [x] 2.2 登录、注册（四个字段）、找回密码（各步）、频道/私聊提示全部走新的 `fieldBox`；验证每个表单里所有输入框的背景宽度相同，空输入框也有完整背景
- [x] 2.3 内容超长时显示末尾可见部分，背景与边界不变、不侵占标签或边框；验证长内容快照
- [x] 2.4 单色终端下输入框以边界字符或反差样式区分且宽度一致；验证单色快照
- [x] 2.5 更新既有渲染快照与表单测试，并在 `docs/client.md` 的登录、注册、找回密码截图里更新输入框外观

## 3. 登录面板

- [x] 3.2 过长错误在末尾截断并在同一行内居中；验证超长文字不换行、不溢出边框
- [x] 3.3 "正在连接"与服务器地址仍显示在底部状态行，不占用错误行；验证两者同时存在时位置正确
- [x] 3.4 已记住状态下密码行改为完整宽度输入框 + 固定数量占位圆点，无文字无光标，圆点数是常量；验证两个密码长度不同的账号显示相同圆点数，且开始输入后圆点清空并恢复普通输入
- [x] 3.5 已记住与普通状态切换时密码输入框的位置、宽度、面板版面不变；验证两种状态的渲染除圆点外逐格一致

- [x] 3.7 更新 `refine-login-panel` 遗留的登录面板测试（它们断言过「已记住登录」提示文字），并在 `docs/client.md` 的「已记住的登录」一节同步改成占位圆点的描述

## 4. 会话列表：分区与底部入口

- [x] 4.1 在 `client` 增加按种类分组的行模型 `[私聊标题][私聊…][群聊标题][群聊…][入口×3]`，标题行不可选；验证私聊与群聊各自按最近活动排序、不跨区、过滤同时作用于两块且不影响入口
- [x] 4.2 `ui.Selected` 改为行模型里可选行的下标，上下键跳过标题行并能连续从私聊走到群聊再到设置、帮助、关于，在「关于」再向下为空操作；验证边界与跨分区移动
- [x] 4.3 渲染三块：两个小标题、各自的空状态与创建引导、底部入口固定在列表区最下方且不随列表滚动；验证会话很多与为空两种情况下入口位置不变
- [x] 4.4 底部入口选中后按 Enter 打开设置、帮助，Esc 关闭后选中项仍在原入口；Alt+S / Alt+H 在任何焦点下仍可用且效果一致；验证全部路径
- [x] 4.5 新增「关于」对话框（应用名、版本、简短说明，Esc 关闭）；版本号用 `-ldflags` 注入、缺省显示 `dev`；验证对话框内容与 Makefile 注入后的输出
- [x] 4.6 新增「私聊」「群聊」「设置」「帮助」「关于」等 i18n 文案（中英）；验证两种语言下渲染无截断错位
- [x] 4.7 选中光效：选中行文字前景色随 `ListShimmer` 变化、整行背景范围不变；列表聚焦且动画开时运行，失焦、折叠、关动画时停止，单色终端降级为移动标记；验证固定时刻的单元格颜色、真值表与三种降级
- [x] 4.8 `needsFrames` 纳入列表光效判定（折叠过渡中不跑光带）；验证真值表与焦点移开后不再请求帧
- [x] 4.9 更新既有的列表、焦点、键位测试，并在 `docs/client.md` 重写主界面左侧的说明与截图、更新快捷键表

## 5. 折叠、展开与名字飞行

- [x] 5.1 增加折叠进度 `a.anim.fold`（0 展开 ~ 1 折叠，复用 `anim.Slide`），布局函数改为 `Layout(content, fold)`：侧栏宽 = `SidebarWidth × (1 − fold)`；验证 fold 取 0、0.3、0.6、1 时各区域的矩形，fold=1 时列表宽度为 0 且聊天区占满整行
- [x] 5.2 折叠目标跟着焦点走：焦点进入输入区则目标折叠，回到列表则目标展开，Enter/右键/Esc/Tab 只是焦点入口；验证每个入口得到相同的折叠目标
- [x] 5.3 `moveFocus` 拦截"没有打开的会话"时去输入区的移动（右键、Tab、Esc），列表保持展开；验证登录后初始态下这些键都不折叠
- [x] 5.4 名字飞行：起点为所选会话在列表中的坐标（钳制在可见区边缘），终点为聊天区标题坐标，位置由同一个 `fold` 插值；折叠进度超过阈值后列表内容不再绘制；验证 fold 在 0、0.3、0.6、1 时名字坐标与列表内容的绘制与否
- [x] 5.5 过渡时限 ≤ 400 ms，期间输入不被阻塞，中途反向从当前进度转向、总时长不累加，关闭动画时一步到位；验证时限、连续按键、反向与关动画四种情形
- [x] 5.6 展开后选中项回到当前会话所在行并保证可见；验证会话在列表靠后位置时展开后选中行可见
- [x] 5.7 焦点标记在新布局下的位置（见 design.md Open Questions，实现时定案并写回 design.md）；验证折叠与展开两种稳态下标记位置
- [x] 5.8 `needsFrames` 纳入折叠过渡，结束后回落到事件驱动；验证过渡中为真、结束后为假
- [x] 5.9 窄屏单栏模式下方向键语义保持（左去列表、右去输入区）；验证窄屏键位
- [x] 5.10 更新既有的焦点切换、动画预算、窄屏折叠测试，并在 `docs/client.md` 写明折叠与展开的行为、左键展开的规则

## 6. 消息流：左右分栏、边框与居中时间

- [x] 6.1 新增布局纯函数 `LayoutMessages(msgs, width, userID, now) []Item`，`Item` 为气泡 / 时间行 / 系统行 / 空行，每个有确定高度；先写测试：他人靠左、自己靠右、气泡宽度 = 内容宽加内边距且不超过区宽的 70%、长消息在气泡内按显示宽度折行
- [x] 6.2 保持合并规则：同一人两分钟内的连续消息同侧相邻，只有每组第一条带发送者名字；他人名字在气泡上方一行，自己的不显示名字；验证合并窗口边界与名字显示
- [x] 6.3 时间行：首条与间隔超过 5 分钟时出现，居中文字、上下各留一个空行、两侧无横线字符；同一天只显示时分、更早的带日期；验证无横线与格式
- [x] 6.4 系统事件居中弱化且无边框，已删除消息显示弱化占位且无边框；验证两种 `Item`
- [x] 6.5 绘制气泡：边框使用 `BubbleSelf` / `BubbleOther`，无 Unicode 时降级为 ASCII，单色下用不同线型区分；验证三种降级下双方可区分、折行与分栏不变
- [x] 6.6 极窄的消息区退化为无边框的左右分栏；验证阈值上下两侧的渲染
- [x] 6.7 滚动仍以行为单位，`Render` 返回的 `total` 为各 `Item` 高度之和，`app` 的滚动钳制不变；验证 PageUp 到顶、End 回底与新消息提示

- [x] 6.9 更新 `docs/client.md` 的消息区截图与说明，更新渲染预览工具 `tools/preview.go` 以输出新布局
