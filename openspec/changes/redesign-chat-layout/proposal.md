# Proposal

## Why

登录面板和聊天主界面各有一批用起来别扭的地方，攒到了值得一起改的程度。

**登录与表单：**

- 登录按钮下方的「忘记密码」「立即注册」是左右并排的，但左右方向键动不了它们，只能用上下键，操作和视觉位置对不上。
- 错误信息挤在面板底部，离出错的地方很远。
- 输入框的背景只铺到文字长度：用户名很短时，只有几个字是深色背景，和下面的密码行参差不齐。注册、找回密码的表单也是同样的做法，同样的问题。
- 有已保存的登录时，密码行显示一句灰色提示，和有密码的状态长得完全不同，版面一跳。

**主界面：**

- 会话列表是一条混排的流，私聊和群聊没有分区，也没有地方放设置、帮助等入口，只能靠 Alt 键记忆。
- 选中一个聊天后，列表仍占着约四分之一的宽度，聊天区被压窄；焦点在两个区域之间切换时，除了一个小竖条，没有任何"东西在动"的感觉，而输入框与登录按钮上已经有光带，风格不统一。
- 消息是左对齐的单栏，自己和对方的话只靠名字颜色区分，长对话里很难一眼看清谁说了什么。
- 时间分隔线是整条横线，抢了视觉重量。

## What Changes

**登录与表单**

- 登录面板的焦点环里，「忘记密码」与「立即注册」可以用左右方向键切换；上下键保持原有行为。
- 登录失败的错误信息显示在**密码行与登录按钮之间**，水平居中，不再放面板底部。
- 所有表单输入框（登录、注册、找回密码）的背景**铺满整个输入宽度**，与内容长度无关，使各行输入框左右边界对齐。
- 有已保存登录、无需输入密码时，密码行仍是同样宽度的输入框，里面显示一串**固定数量**的占位圆点，不反映真实密码长度，也没有文字和光标。

**主界面左侧**

- 左侧分为三块，自上而下：**私聊**、**群聊**、**底部入口**（设置、帮助、关于）。底部入口是可用方向键选中、Enter 打开的条目，与列表共用同一套选中态。
- 左侧选中项带**光效**（复用已有的光带动画），受统一动画开关控制，开关关闭或终端无彩色时降级。
- 新增「关于」对话框。

**聊天区**

- 会话选中后，左侧列表**完全折叠**，聊天区扩展到整行宽度；被选会话的名字从列表中的位置**飞入**聊天区左上角。按左方向键（输入框光标在行首时）反向：名字飞回列表，列表重新展开。动画受统一开关控制，关闭后瞬时完成。
- 消息改为**左右分栏**：对方的消息靠左，自己的靠右。
- 双方的消息各用**不同颜色的边框**圈起来。
- 时间只作为**居中的一行文字**穿插在消息之间，前后留出空白，不再画整条横线。

**启动行为**

- 登录后进入主界面时，列表展开、焦点在列表上，**不再自动打开最近的会话**。这是因为折叠状态与"已选会话"绑定，自动打开会让用户一登录就看不到左侧结构。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `tui-chat-client`：主界面布局（左侧三分区、折叠与展开、聊天区左右分栏）、会话列表（私聊/群聊分区）、消息流渲染（左右对齐、边框、居中时间）、区域焦点的方向语义（折叠态下的左键）、登录面板结构（左右键）、已保存会话的登录面板（占位圆点）、注册表单与找回密码流程（输入框铺满）、输入框的错误位置。
- `tui-design-system`：行样式与选中态（选中光效）、边框与分隔线（消息边框属于例外）、输入框的统一外观。

## Impact

**行为变更（BREAKING，仅对使用习惯而言）**

- 登录后不再自动打开会话，焦点从输入框变为列表。
- 选中聊天后左侧列表不再常驻，要看列表需按左键。
- 「主界面不使用整块边框」这一条设计规则需要放宽：消息气泡带边框。边框仅用于消息，主界面外框和区域之间仍不画框。

**代码**

- `pkg/tui/views/list.go`：列表拆成私聊、群聊、底部入口三块；选中光效；折叠态。
- `pkg/tui/views/transcript.go`：消息左右分栏、边框、居中时间；标题区接收飞入的名字。
- `pkg/tui/views/dialogs.go`：输入框铺满与占位圆点（`fieldBox`）；登录错误位置；关于对话框。
- `pkg/tui/views/focus.go` 与 `pkg/app/anim.go`：折叠/展开与名字飞行的时间轴，纳入 `needsFrames`。
- `pkg/client/state.go`：底部入口的选中状态；会话按种类分组的可见列表。
- `pkg/app/keys.go`、`pkg/app/render.go`、`pkg/app/app.go`：方向键语义、登录后初始焦点、渲染编排。
- `pkg/i18n`：「私聊」「群聊」「关于」等文案。
- `pkg/tui/theme`：两个消息边框色令牌（自己、对方），`ink` 与 `paper` 各一组，并有 256 色与单色降级。

**依赖**：无新增。光效复用 `pkg/tui/anim`。

**测试与文档**：既有的焦点、布局、渲染快照与端到端测试需要随新布局更新；`docs/client.md` 的主界面截图与快捷键说明需要重写。

**与进行中的变更的关系**：`refine-login-panel` 尚有一项未完成（5.4，渲染预览人工确认），本变更会修改同一批登录面板需求。本变更的 delta 以 `refine-login-panel` 完成并归档后的主 spec 为基线，因此应在其归档之后再应用。
