# Spec Delta

## MODIFIED Requirements

### Requirement: 状态栏与连接状态

底部状态栏 SHALL 持续显示连接状态、当前用户与关键操作提示。连接异常 MUST 清晰可见并给出下一步动作。主界面上的操作提示 MUST 只有一句：如何打开快捷转盘，而不再逐个列出快捷键。

#### Scenario: 在线状态展示
- **WHEN** 连接正常且已认证
- **THEN** 状态栏显示当前用户名与在线指示，并显示「<呼出键> 打开快捷转盘」，呼出键为设置中选定的键（默认 Ctrl+Space）

#### Scenario: 断线提示
- **WHEN** 与服务端的连接断开
- **THEN** 状态栏立即转为警告样式并显示重连倒计时，输入区进入只读并保留草稿

#### Scenario: 重连成功后的补偿
- **WHEN** 客户端重连并重新认证成功
- **THEN** 客户端补拉断开期间的消息，并将状态栏恢复为在线

#### Scenario: 认证过期
- **WHEN** 重连时令牌已过期
- **THEN** 客户端提示需要重新登录并打开登录界面，不进入无限重连

### Requirement: 快捷键与可发现性

所有关键操作 MUST 有键盘快捷键，且快捷键 MUST 能在界面内被发现，不依赖用户阅读外部文档。当前页面可用的操作 SHALL 通过快捷转盘发现；完整的快捷键说明在帮助页。

#### Scenario: 快捷键提示常驻
- **WHEN** 用户处于主界面
- **THEN** 状态栏提示如何打开快捷转盘，转盘里列出当前页面可用的操作

#### Scenario: 帮助面板
- **WHEN** 用户按下帮助键
- **THEN** 客户端在右侧显示完整的快捷键说明页面，按功能分组展示，内容超出时可上下滚动，并说明快捷转盘的用法

#### Scenario: 打开对话框时的键位上下文
- **WHEN** 某个对话框处于打开状态
- **THEN** 主界面的快捷键与快捷转盘都不生效，对话框内按 Esc 关闭并返回原位置
