- [x] 4.7 实现频道创建/加入/退出/删除与私聊会话标识生成，验证双方得到同一私聊标识、第三方访问返回 `forbidden` 的测试通过
- [x] 4.8 实现消息校验、序号分配、广播与发送确认，验证并发发送无重复序号、重试不产生重复消息的测试通过
- [x] 4.9 实现历史分页补发与向前翻页，验证 500 条消息会话的分页无重复无遗漏
- [x] 4.10 实现消息编辑与删除（含已删除占位与频道创建者权限），验证四条权限场景测试通过
- [x] 4.11 实现在线状态跟踪与多端登录下的离线判定，验证"关一个客户端不广播离线"的测试通过
- [x] 4.12 实现 TLS 直连监听与反向代理信任模式（含伪造来源头防护），验证非信任模式下来源头被忽略
- [x] 4.13 实现慢客户端积压处理（队列超限关连接），验证慢连接不影响同频道其他接收方的延迟
- [x] 4.14 实现心跳与超时关闭，验证失联客户端在两倍心跳周期后被清理且在线状态更新
- [x] 4.15 实现健康检查端点、分级日志（不含密码/令牌/消息正文）与优雅关停，验证关停前已确认消息在重启后仍存在
