# Spec Delta

## Purpose

定义服务端进程的运行契约：启动与配置、监听与加密、存储的持久化语义、优雅关停与可观测性。它保证服务端在异常与重启面前不会丢消息、不会写坏数据，并让运维能判断它在做什么。

## ADDED Requirements

### Requirement: 启动配置

服务端 SHALL 从配置文件与命令行参数读取运行参数，并支持环境变量覆盖。缺少必需参数时 MUST 拒绝启动并给出明确原因，而不是以默认值静默运行。

#### Scenario: 首次启动生成默认配置
- **WHEN** 服务端在没有任何配置文件的情况下首次启动
- **THEN** 服务端在配置路径生成带注释的默认配置文件，并提示需要设置的必填项

#### Scenario: 必填项缺失
- **WHEN** 配置中缺少监听地址或数据目录
- **THEN** 服务端打印具体缺失项并以非零状态码退出

#### Scenario: 环境变量覆盖配置
- **WHEN** 配置文件中 `listen` 为 `:8100` 而环境变量指定了其他端口
- **THEN** 服务端使用环境变量中的值，并在启动日志中说明该值来源

#### Scenario: 配置非法
- **WHEN** 配置中端口超出合法范围或数据目录不可写
- **THEN** 服务端拒绝启动并指出具体字段与原因

### Requirement: 监听与传输加密

服务端 SHALL 支持直接以 TLS 监听，也支持在反向代理之后以明文监听。以明文监听时 MUST 能通过配置显式声明"信任上游代理的转发信息"，否则 MUST NOT 采信客户端自报的来源地址。

#### Scenario: 以 TLS 直接监听
- **WHEN** 配置提供证书与私钥路径且 TLS 监听启用
- **THEN** 服务端仅接受加密连接，明文连接被拒绝

#### Scenario: 反向代理模式
- **WHEN** 配置声明信任上游代理
- **THEN** 服务端从代理提供的头部读取真实来源地址，用于限流与日志

#### Scenario: 非信任模式下忽略伪造头
- **WHEN** 未声明信任上游代理，客户端自行伪造来源头
- **THEN** 服务端忽略该头部，以实际连接地址为准

#### Scenario: 证书加载失败
- **WHEN** 证书文件不存在或与服务端私钥不匹配
- **THEN** 服务端拒绝启动并明确指出证书问题

### Requirement: 数据持久化语义

服务端 MUST 将用户、频道、成员关系与消息持久化到本地存储。写操作 MUST 串行化并原子提交，进程在写入中途崩溃时 MUST NOT 留下损坏的数据文件。

#### Scenario: 原子写入
- **WHEN** 服务端在写入数据文件的过程中进程被强制结束
- **THEN** 重新启动后读取到的是写入前或写入后的完整状态，不存在半截文件

#### Scenario: 并发写入有序
- **WHEN** 多个连接几乎同时触发写操作
- **THEN** 所有写操作按顺序完成，最终状态包含全部成功操作

#### Scenario: 磁盘不可写时拒绝服务
- **WHEN** 数据目录在运行中变为不可写
- **THEN** 服务端拒绝新的写请求并返回明确错误，读请求仍可用，同时记录错误日志

#### Scenario: 重启后数据完整
- **WHEN** 服务端正常关停后重新启动
- **THEN** 全部用户、频道与消息与关停前一致

### Requirement: 存储抽象

存储访问 MUST 通过一个可替换的接口完成，业务逻辑 MUST NOT 直接依赖文件格式。这使得未来在不改变聊天行为的前提下替换持久化实现。

#### Scenario: 业务层不感知文件格式
- **WHEN** 以替换实现的方式改变底层存储
- **THEN** 协议行为与所有规格中的场景保持不变

#### Scenario: 存储错误被统一映射
- **WHEN** 底层存储返回错误
- **THEN** 服务端将其映射为协议错误码，不向客户端暴露文件路径或内部细节

### Requirement: 优雅关停

服务端 MUST 在收到终止信号后停止接受新连接，完成进行中的写操作，通知已连接客户端，并在超时内退出。

#### Scenario: 关停时通知客户端
- **WHEN** 服务端收到终止信号
- **THEN** 已连接客户端收到服务不可用通知并进入重连流程

#### Scenario: 关停不丢已确认消息
- **WHEN** 服务端在关停前已向发送方确认了某条消息
- **THEN** 该消息在重启后仍存在于历史中

#### Scenario: 关停超时强制退出
- **WHEN** 关停等待超过配置的上限仍未完成
- **THEN** 服务端记录未完成的连接并强制退出，退出码表明非正常关停

### Requirement: 运行日志

服务端 SHALL 记录连接建立与断开、认证失败、限流触发、持久化错误与关停过程。日志 MUST NOT 包含密码、令牌原文或完整消息内容。

#### Scenario: 认证失败被记录
- **WHEN** 某来源登录失败
- **THEN** 日志记录来源、用户名与失败原因，不含尝试的密码

#### Scenario: 日志不含令牌
- **WHEN** 用户登录成功后检查日志
- **THEN** 日志中不出现签发的令牌字符串

#### Scenario: 日志级别可配置
- **WHEN** 运维将日志级别设为更严格的档位
- **THEN** 低级别日志不再输出，错误级别日志仍然输出

### Requirement: 健康检查

服务端 SHALL 提供健康检查端点，用于判断进程是否可接受流量与存储是否可用。

#### Scenario: 正常状态
- **WHEN** 进程运行且存储可读写
- **THEN** 健康检查返回成功状态

#### Scenario: 存储异常
- **WHEN** 存储不可写
- **THEN** 健康检查返回失败状态与简要原因，便于负载均衡摘除该实例
