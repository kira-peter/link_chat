# Spec Delta

## ADDED Requirements

### Requirement: 命令行创建超级管理员

服务端 SHALL 提供命令行方式创建或提升超级管理员：指定数据目录与用户名后，从终端无回显地读取两次密码。用户名不存在时创建账号；已存在时将其提升为超级管理员，且不修改其密码。完成后进程 MUST 退出而不启动服务。

#### Scenario: 创建超级管理员
- **WHEN** 运维在服务端未运行时执行创建超级管理员命令并输入两次一致的密码
- **THEN** 该账号被创建为超级管理员，命令以零状态码退出

#### Scenario: 提升已有账号
- **WHEN** 对已存在的用户名执行该命令
- **THEN** 该账号成为超级管理员，原密码不变

#### Scenario: 两次密码不一致
- **WHEN** 两次输入的密码不一致或不满足强度要求
- **THEN** 命令打印原因并以非零状态码退出，数据不变

### Requirement: 命令行重置密码

服务端 SHALL 提供命令行方式为任意账号（包括超级管理员）重置密码：从终端无回显地读取两次新密码，更新后作废该账号的全部令牌并写入审计日志，完成后退出而不启动服务。

#### Scenario: 超级管理员忘记密码
- **WHEN** 运维在服务端未运行时对超级管理员执行重置密码命令并输入两次一致的新密码
- **THEN** 密码被更新，旧令牌全部失效，命令以零状态码退出

#### Scenario: 账号不存在
- **WHEN** 对不存在的用户名执行重置密码命令
- **THEN** 命令打印账号不存在并以非零状态码退出

### Requirement: 数据目录独占

服务端运行期间 MUST 独占数据目录。另一个服务端进程或创建超级管理员命令在数据目录已被占用时 MUST 拒绝执行并说明原因。进程异常退出后残留的占用标记 MUST NOT 永久阻止下次启动。

#### Scenario: 运行中执行命令
- **WHEN** 服务端正在运行，运维对同一数据目录执行创建超级管理员命令
- **THEN** 命令提示需要先停止服务端，并以非零状态码退出

#### Scenario: 异常退出后重启
- **WHEN** 服务端被强制结束后再次启动
- **THEN** 服务端正常启动

### Requirement: 后台开关

配置 SHALL 提供管理后台开关，默认开启，并支持环境变量覆盖。

#### Scenario: 关闭后台
- **WHEN** 配置中关闭了管理后台
- **THEN** 服务端启动日志说明后台已关闭，`/admin/` 返回 404

### Requirement: 最近日志缓冲

服务端 SHALL 在内存中保留最近 500 条运行日志，供管理后台读取。这些日志与输出到终端的内容一致，同样 MUST NOT 包含密码、令牌原文或消息正文。

#### Scenario: 后台读取最近日志
- **WHEN** 服务端已运行并产生超过 500 条日志
- **THEN** 后台可读到最新的 500 条，按时间顺序排列
