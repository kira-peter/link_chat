## 4. 客户端同步

- [x] 4.1 登录成功后在后台发 `settings.get`：已有设置则覆盖缓存并应用；不存在则上传当前缓存；失败或超时保持缓存且不弹错误；`invalid_argument` 视为服务端不支持，本次连接不再发起设置请求且不提示；验证：测试覆盖上述四种结果，使用假传输层断言请求次数
- [x] 4.2 设置页确认账号设置后：本地立即生效、写缓存、后台 `settings.put`；失败时状态栏提示未能同步（新增中英文案），本地保留；放弃与浏览候选不上传；记住登录不上传；验证：测试断言请求内容与次数，失败提示出现，文案在两种语言下不超出状态栏
