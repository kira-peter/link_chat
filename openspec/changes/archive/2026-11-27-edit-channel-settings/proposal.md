# Proposal

## Why

创建者曾在选择可见性时误按回车提交，且创建后无法修改频道。需要把选项确认与表单提交分开，并允许创建者调整频道，同时让在线用户看到正确的可加入列表。

## What Changes

- 新建和编辑复用同一表单。简介自动折行并显示字数，公开开关向右开启、向左关闭，底部提供明确的提交和取消按钮。
- 频道消息用星标区分创建者。创建者可用 `Alt+E` 或快捷转盘修改频道名称、简介和可见性。
- 公开转私有时，频道从非成员的推荐列表中消失，现有成员和历史消息保留。私有转公开时，在线用户收到发现通知。
- 旧服务端拒绝编辑时，客户端提示更新并重启服务端，保留草稿。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `chat-rooms`：创建者编辑频道属性及公开、私有切换后的可见范围。
- `chat-protocol`：频道编辑请求、握手能力标记和目录更新事件。
- `tui-chat-client`：频道表单、创建者标记和编辑入口。

## Version

Minor，`6.0.0` → `6.1.0`。本变更扩展已有能力。

## Impact

- 涉及终端客户端、WebSocket 协议、服务端及频道存储。
- 协议变更兼容已有客户端。编辑频道需运行支持该操作的服务端。
