# Spec Delta

## MODIFIED Requirements

### Requirement: 登录与首启引导

客户端 SHALL 用一个自足的登录面板完成身份认证，并在失败时给出可操作的说明。服务器地址 MUST 来自客户端配置而非常驻的输入字段，默认指向本机。

#### Scenario: 首次启动
- **WHEN** 客户端没有任何有效配置
- **THEN** 客户端打开登录面板，只要求用户名与密码，服务器地址取配置中的默认值

#### Scenario: 服务器地址来自配置
- **WHEN** 用户需要连接另一台服务器
- **THEN** 用户修改配置文件或用启动参数指定地址，登录面板本身不提供该字段

#### Scenario: 服务器不可达
- **WHEN** 配置中的服务器地址无法建立连接
- **THEN** 登录面板显示不可达提示与正在使用的地址，并保留已填的用户名供重试

#### Scenario: 登录失败
- **WHEN** 用户提交错误凭据
- **THEN** 客户端在面板内显示失败原因（凭据错误、被限流等），不清空用户名

#### Scenario: 令牌持久化
- **WHEN** 用户登录成功并退出客户端后再次启动
- **THEN** 客户端使用已保存的令牌直接进入主界面，无需重新输入密码

## ADDED Requirements

### Requirement: 登录面板结构

登录面板 MUST 由用户名输入、密码输入、登录按钮三部分组成，按钮下方 MUST 提供「忘记密码」与「立即注册」两个可点击的文字链接。所有可交互元素 MUST 可用键盘到达，且当前焦点 MUST 有明确视觉标识。

#### Scenario: 面板包含两个字段、一个按钮、两个链接
- **WHEN** 登录面板渲染完成
- **THEN** 自上而下依次可见用户名、密码、登录按钮、忘记密码链接、立即注册链接

#### Scenario: Tab 在全部可交互元素间循环
- **WHEN** 用户反复按 Tab
- **THEN** 焦点依次经过用户名、密码、登录按钮、忘记密码、立即注册并回到用户名，任何时刻都恰好有一个元素处于焦点

#### Scenario: Enter 激活当前焦点
- **WHEN** 焦点在登录按钮上按 Enter
- **THEN** 提交登录；焦点在某个链接上按 Enter 时激活该链接

#### Scenario: 鼠标点击链接
- **WHEN** 终端支持鼠标事件且用户点击「立即注册」
- **THEN** 打开注册表单

#### Scenario: 链接的视觉表现
- **WHEN** 渲染「忘记密码」与「立即注册」
- **THEN** 二者以带下划线的文字呈现，与按钮在视觉上可区分

### Requirement: 注册表单

注册表单 SHALL 收集用户名、密码、安全问题与安全答案。安全问题 MUST 可从预置列表中选择，也 MUST 允许用户自行输入。

#### Scenario: 从预置问题中选择
- **WHEN** 用户在注册表单的安全问题字段上按 Enter 或空格
- **THEN** 展开预置问题列表，选中其中一项后该问题填入字段

#### Scenario: 自定义问题
- **WHEN** 用户在预置列表之外输入自己的问题文本
- **THEN** 该文本被作为安全问题提交

#### Scenario: 提交不完整
- **WHEN** 任一必填项为空时用户提交注册
- **THEN** 客户端把焦点移到第一个空字段并提示该字段必填，不发出请求

#### Scenario: 返回登录
- **WHEN** 用户在注册表单上按 Esc
- **THEN** 返回登录面板，已填的用户名保留

### Requirement: 找回密码流程

找回密码 MUST 是一个三步向导：输入用户名、回答问题、设置新密码。每一步 MUST 能返回上一步，且 MUST 显示当前处于第几步。

#### Scenario: 第一步输入用户名
- **WHEN** 用户从登录面板选择「忘记密码」
- **THEN** 向导显示用户名输入，预填登录面板中的用户名

#### Scenario: 第二步显示问题
- **WHEN** 第一步提交的用户名存在问题
- **THEN** 向导显示该账号的安全问题与答案输入框

#### Scenario: 用户名不可找回
- **WHEN** 第一步提交的用户名不存在或没有安全问题
- **THEN** 向导显示「该账号无法找回，请联系管理员」并停留在第一步

#### Scenario: 第三步设置新密码
- **WHEN** 答案校验通过
- **THEN** 向导显示新密码与确认密码两个输入框

#### Scenario: 两次输入不一致
- **WHEN** 新密码与确认密码不一致
- **THEN** 客户端提示不一致且不提交，焦点回到确认字段

#### Scenario: 重置成功回到登录
- **WHEN** 重置成功
- **THEN** 向导关闭，登录面板打开并预填用户名，提示可用新密码登录

#### Scenario: 重置令牌过期
- **WHEN** 第三步提交时服务端返回令牌过期
- **THEN** 向导回到第一步并说明需要重新开始

#### Scenario: 任一步可返回
- **WHEN** 用户在第二或第三步按 Esc
- **THEN** 向导返回上一步，已填内容保留
