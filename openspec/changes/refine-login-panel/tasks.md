# Tasks

- [x] 1.1 在 `pkg/tui/anim` 增加按钮专用的 `ButtonShimmer`（更窄的带宽，行进范围含内边距），与输入框的 `DefaultShimmer` 分开，验证光带中心在整个按钮内部宽度内线性行进且两端熄灭

## 2. 登录面板版式

- [x] 2.1 `LoginModel` 增加 `Remembered`；字段标签与输入改为同一行，标签列按当前语言取最大宽度对齐，验证中英文下两个输入的起始列相同
- [x] 2.2 面板高度从 15 行缩减到 12 行左右，验证渲染行数下降且全部元素仍可见、不被边框截断
- [x] 2.3 已记住状态下密码行显示「已记住登录 · 按 Enter 直接登录」而不是输入框，验证渲染快照中无掩码字符与光标

## 3. 登录按钮

- [x] 3.1 按钮改为带边框的紧凑方框，宽度由文字加固定内边距决定，居中，验证按钮宽度小于字段宽度且四边有边框字符
- [x] 3.2 选中态边框与文字用强调色、未选中用弱化色，验证两种状态下关键单元格的前景色不同
- [x] 3.3 选中时按钮文字逐单元格应用光带颜色，边框与文字位置不变，验证固定时刻的单元格颜色
- [x] 3.4 动画关闭、未选中、单色终端三种情况的降级表现，验证各自的断言（静态色 / 无光带 / 单个标记）
- [x] 3.5 `needsFrames` 把"登录面板打开且焦点在按钮且动画开"纳入判定，验证真值表，并验证焦点移开后不再请求帧

## 4. 启动流程与登录路径

- [x] 4.1 `New()` 无论有无已保存令牌都打开登录面板，有令牌时 `Remembered=true`、焦点在登录按钮，用户名预填；`Run()` 不再自动 resume，验证启动后未向服务端发起任何认证请求
- [x] 4.2 提交登录时按 `Remembered` 选择 resume 或密码登录，验证两条路径各自调用正确的操作
- [x] 4.3 放弃已保存会话的三个条件（改用户名、输入密码、令牌失效）都会把 `Remembered` 置假，验证各条件的键位与流程测试
- [x] 4.4 令牌失效时回落：清除令牌、显示原因、焦点移到密码行；网络错误时**不**清除令牌，验证两种失败的不同处理
- [x] 4.5 关闭"记住登录"后登录面板显示普通密码输入，验证无已记住状态
