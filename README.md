## 特性

- **频道与私聊** — 公开频道、一对一私聊，会话列表按最近活动排序，带未读计数
- **克制的中文终端界面** — 语义色彩令牌 + 固定间距网格，选中态是整行背景而不是反色；CJK 与 emoji 按实际显示宽度折行，不错位
- **连续消息合并** — 同一个人的连续消息只显示一次名字，时间只在需要的地方出现
- **断线自愈** — 指数退避重连，重连后按序号补拉，不重不漏；登录过期会回到登录界面而不是无限重试
- **草稿保留** — 按会话保存；发送失败时内容退回输入框
- **不打断阅读** — 翻看历史时来了新消息只给提示，不抢滚动位置
- **账号找回** — 注册时设置安全问题，忘记密码可三步自助重置；重置后强制登出所有旧会话
- **中英双语** — 运行时切换，立即生效
- **两套主题** — `ink` / `paper`，自动按终端能力降级（ASCII 边框、256 色、无彩色）

## 快速开始

```bash
make build

# 终端 1：启动服务端（首次运行会生成配置）
./build/link-chat-server -config server.json -data ./data

# 终端 2、3：启动两个客户端
./build/link-chat
```

首次启动客户端打开登录面板，只要求用户名和密码。服务器地址来自配置，默认指向本机 `ws://127.0.0.1:8100/ws`，要改就改配置或加 `-server` 参数。

点面板下方的「立即注册」建账号——注册时需要设置一个安全问题，它是日后忘记密码时唯一的找回途径。忘记密码时点「忘记密码」，三步走完即可重设。

## 架构

```
cmd/link-chat-server    服务端入口
cmd/link-chat           客户端入口
pkg/protocol            WebSocket JSON 信封协议，两端共享
pkg/storage             Storage 接口 + JSON 文件实现（单写者协程 + 原子提交）
pkg/server              连接管理、认证、限流、消息路由
pkg/client              连接状态机、重连、AppState 归约
pkg/tui/theme           语义色彩令牌与主题
pkg/tui/layout          间距网格、折行与宽度计算（纯函数）
pkg/tui/widget          绘制原语
pkg/tui/views           界面渲染（状态 → 单元格，纯函数）
pkg/app                 把传输层、状态与视图连起来的主循环
```

几条贯穿全局的设计约束：

- **协议层独立**，服务端与客户端共享类型，协议不兼容在编译期暴露。
- **存储可替换** — 业务代码只依赖 `Storage` 接口，换 SQLite 只需新增一个实现。
- **渲染是纯函数** — 视图接收状态、输出单元格，因此界面可以在没有终端的情况下被测试和快照。
- **宽度只有一个来源** — `layout.StringWidth` 跟随终端的实际规则，任何地方都不直接调 `runewidth`。
