# link_chat 客户端

终端聊天客户端。主界面是会话列表与聊天区两栏：选中会话后列表折叠、聊天区占满整行，底部是输入框。

## 安装与启动

```bash
make build-client
./build/link-chat                               # 默认实例
./build/link-chat -as alice                     # 名为 alice 的实例
./build/link-chat -server ws://host:8100/ws     # 临时指定服务器
./build/link-chat -config ./my.json             # 直接指定配置文件
./build/link-chat -version                      # 打印版本后退出，如 link-chat 1.0.0
```

## 同一台机器上登录多个账号

每个实例有自己的凭据文件，所以开两个窗口就能登录两个账号：

```bash
./build/link-chat -as alice     # 终端 1
./build/link-chat -as bob       # 终端 2
```

实例名决定配置文件位置：

```
%APPDATA%\link-chat\instances\alice.json
%APPDATA%\link-chat\instances\bob.json
```

- 不传 `-as` 时实例名为 `default`，多个不带参数的客户端**共享**同一份凭据——第二个会直接沿用第一个的登录状态。这正是需要 `-as` 的原因。
- 实例名只能用字母、数字和 `_ - .`。
- 从旧版本升级时，若 `instances/default.json` 不存在而旧的 `config.json` 存在，会自动迁移一次，不需要重新登录。

每次启动都会先打开登录面板：用户名、密码、登录按钮，按钮下面是「忘记密码」和「立即注册」两个链接。已有保存的登录时，面板预填用户名、焦点落在登录按钮上，按一次 `Enter` 即可登录（见下文「已记住的登录」）。

**服务器地址不在登录面板里。** 它来自配置文件，默认 `ws://127.0.0.1:8100/ws`（本机）。要连别的服务器，按优先级从高到低：

1. 启动参数 `-server wss://chat.example.com/ws`
2. 配置文件里的 `server` 字段
3. 内置默认值

地址可以省略协议和路径：

| 你写的 | 实际连接 |
|---|---|
| `chat.example.com` | `ws://chat.example.com/ws` |
| `chat.example.com:8100` | `ws://chat.example.com:8100/ws` |
| `wss://chat.example.com/ws` | 原样使用 |

公网请用 `wss://`。

## 登录面板

```
┌─ 登录 ─────────────────────────────────────────┐
│                                                │
│   用户名  [ alice                          ]   │
│                                                │
│   密码    [ █                              ]   │
│                                                │
│                                                │
│                  ┌──────────┐                  │
│                  │   登录   │                  │
│                  └──────────┘                  │
│                                                │
│              忘记密码    立即注册              │
│                                                │
└────────────────────────────────────────────────┘
```

上图是单色终端下的样子。彩色终端里，每个输入框是一整条背景色块，焦点所在的那一条更亮；单色终端没有背景色可用，就用两端的方括号标出输入框的范围。

**输入框始终铺满整个输入宽度，与内容长短无关。** 用户名只有两个字时，背景也和密码框一样宽、左右边界对齐；空的输入框同样看得出范围。内容比输入框更长时，显示末尾的部分（光标在那里），不会撑破边框。注册、找回密码、新建频道与私聊的输入框都是同样的外观。

标签和输入框在同一行。登录按钮是一个带边框的小方框，聚焦时边框和文字变为强调色，并有一道光带从左到右扫过文字；关闭动画、或终端不支持彩色时，光带会降级为静态颜色或单个移动的标记。

`Tab` / `Shift+Tab` 在五个元素之间循环（用户名、密码、登录按钮、忘记密码、立即注册），`Enter` 激活当前焦点。两个链接带下划线，聚焦时变为强调色。终端支持鼠标时也可以直接点击。

两个链接是左右并排的，所以焦点在其中一个上时，可以用 `←` / `→` 在它们之间切换；在最左或最右那个上继续往外按是空操作，不会绕到另一个，也不会离开这一行。`↑` / `↓` 仍然在整个面板里上下移动焦点，`Tab` 的循环顺序也没有变。在输入框和登录按钮上，`←` / `→` 不起作用。

**错误信息显示在密码框与登录按钮之间**，水平居中，用红色。这一行是常驻预留的：没有错误时是空行，所以错误出现或消失时，面板的高度和按钮、链接的位置都不会跳动。太长的错误会在行尾截断，而不是换行。按下登录后，这一行显示「正在登录…」。

**面板里不显示服务器地址，也没有按键提示行**：平时它们都用不上。只有连不上服务器时，错误行才会写出正在连接的地址，例如「连不上 ws://127.0.0.1:8100/ws」，这样你能分辨是地址写错了还是服务没起来。

**客户端版本过旧。** 客户端连上服务器时会报告自己的版本。服务器可以要求一个最低版本，版本更低的客户端会被拒绝，错误行显示「客户端 0.2.9 过旧，请升级到 0.3.0」。这时客户端不再自动重连：重试多少次结果都一样。如果你是在登录状态下断线、重连时才被拒的，会回到登录面板显示同样的提示。已保存的登录不会被清除，升级之后可以直接用它恢复，不必重新输入密码。

### 登录舞台

登录、注册、找回密码期间，屏幕上**只有面板本身**，居中显示，背后不画主界面的任何东西：没有标题栏、没有会话列表、没有状态栏和快捷键提示——那时它们都还用不上。

面板四周是一片稀疏的淡色小点，缓慢地斜向漂移，像夜空。点不会出现在面板里，也不会贴着面板的边框。窗口小到面板四周已经没有空地时，就只显示面板。

点的漂移只用很低的刷新率（约每秒 10 帧），离开登录界面就停。关闭动画（`Alt+M`，或配置里的 `motion_off`）后点仍然显示，但静止不动，也不再刷新。

### 登录成功的入场动画

登录成功后有一段约 0.6 秒的入场动画，「收成一线再展开」：

1. 登录面板上下压扁，最后只剩一条横线；
2. 横线向左右拉长到整行宽，成为一道亮线，背景的点同时淡出；
3. 亮线分成上下两条，向屏幕上下两侧张开，主界面在两条线之间从中间露出来；
4. 两条线停在标题栏下方和状态栏上方，正好变成主界面原有的两条分隔线。

几点约定：

- **按任意键立即结束动画**，这个键照常生效（比如按 `↓` 会直接移动列表的选中项），不会被动画吞掉。
- 动画期间到达的会话列表、消息照常显示在已经露出的部分里。
- 动画结束的那一帧和直接显示主界面完全一样，不留残影。
- 从注册、找回密码后登录也会播放；**断线重连成功不播放**，因为那时主界面一直都在。
- 关闭动画时没有入场动画，登录后直接显示主界面。
- 单色或 256 色终端里，亮线改用粗线 `━` 表示；不支持框线字符的终端用 `=`。

### 退出登录

在「我」页面选「退出登录」，会弹出确认框：说明「确定要退出当前账号吗？本机保存的登录信息会保留。」，下面是两个**等宽、居中**的方框按钮「取消」「退出」。

- 默认选中「取消」，所以误按 `Enter` 不会退出。
- `←` `→` 或 `Tab` 在两个按钮之间切换；选中的按钮边框高亮，文字上有光带扫过，「退出」选中时是红色。
- `Enter` 执行选中的按钮，`Esc` 等同于取消。

**退出登录不会删除本机保存的登录。** 退出只是结束这次会话、回到登录界面：用户名已经填好，密码框是占位圆点，焦点在登录按钮上——按一次 `Enter` 就回来了。想让这台机器彻底不保存登录，请在设置里把「记住登录」关掉，那会立即删除已保存的凭据。

确认退出后，会播放入场动画的**倒放**：主界面上下两条分隔线向中间合拢，把主界面收进去，合成一条亮线，亮线缩短到面板的宽度，再展开成登录面板，背景的点同时浮现。和入场一样，按任意键立即跳到终点（这个键会作用在登录面板上），关闭动画时直接显示登录界面。退出时断开连接在后台进行，网络慢也不会卡住界面。

### 切换账号

在「我」页面选「切换账号」按 `Enter`，**不弹确认**（切换不会丢失任何东西），直接播放退场动画，回到和登录界面同样的背景上，出现**账号列表**：

```
┌─ 选择账号 ─────────────────────────────────────┐
│                                                │
│   ┌────────────────────────────────────────┐   │
│   │                 alice           已记住 │   │
│   └────────────────────────────────────────┘   │
│   ┌────────────────────────────────────────┐   │
│   │                  bob          需要密码 │   │
│   └────────────────────────────────────────┘   │
│   ┌────────────────────────────────────────┐   │
│   │              使用其他账号              │   │
│   └────────────────────────────────────────┘   │
└────────────────────────────────────────────────┘
```

- 列表里是这台机器上**最近登录过的所有账号**，最近的在前，最多 10 个；每个账号注明是「已记住」还是「需要密码」。
- `↑` `↓`（或 `Tab`）移动，光标所在的那个账号像登录按钮一样高亮并有光带扫过。到首尾时循环到另一端。
- 选中一个**已记住**的账号按 `Enter`：直接用保存的登录进入，同样播放登录成功的入场动画。
- 选中一个**需要密码**的账号（比如那个账号关闭了「记住登录」）：进入登录面板，用户名已填好，焦点在密码框。
- 「使用其他账号」：进入空白的登录面板。
- `Esc`：回到当前账号的登录面板，和退出登录后一样。

每个账号的登录**分别保存**，切来切去不会让别的账号丢掉已保存的登录。配置文件里只记账号名（`accounts` 字段），令牌在系统凭据库里，每个账号一条。

### 已记住的登录

有保存的登录时，用户名已预填，焦点直接落在登录按钮上；密码那一行**仍然是一个和普通密码一样宽的输入框**，里面是固定数量的圆点，没有文字，也没有光标。

这些圆点只表示「这里有已保存的登录」，**数量是固定的，和你真实密码的长度无关**（客户端本来也不知道密码），所以不会泄露长度。密码框保持原样而不是换成一句提示，是为了让面板在「已记住」与「普通」两种状态之间切换时形状不变、不跳动。

不需要输入任何东西，按一次 `Enter` 即可登录；底部常驻的提示行里有「Enter 确认」。一旦你在密码框里输入字符，圆点就会清空，面板恢复成普通的密码输入。

**为什么启动后还要按一次 Enter？** 同一账号同一时刻只有一处能在线，恢复登录会把别处的登录顶下线。如果启动时自动恢复，你只是「打开了程序」就可能把另一台机器上正在用的会话踢掉。所以现在启动本身不会登录，是否登录由你按下按钮决定。

以下任一情况会放弃已保存的登录，面板回到普通的密码登录（保存的凭据本身不会因此被删除）：

- 修改用户名（保存的登录属于特定账号）；
- 往密码栏输入或删除字符；
- 保存的登录已失效（过期、被吊销、或在别处被顶掉）：此时凭据会被清除，面板显示原因，光标移到密码栏。

如果只是网络不通或服务端没起来，**不会**清除保存的登录，直接再按一次 `Enter` 重试即可。

服务器地址来自配置，不是一个可输入的字段；连不上时它会出现在错误信息里。

**密码连续输错后的等待。** 同一账号来自同一出口地址连续输错密码时，等待时间会逐级拉长：前三次可以直接重试，之后依次是 1 分钟、5 分钟、15 分钟、1 小时、3 小时、8 小时，第十次起从 1 天开始每次翻倍。等待期间登录面板显示「等待 4 分 12 秒后可重试」这样的倒计时，按 `Enter` 不会发送请求，倒计时归零后自动恢复，不需要重连或重启。输对一次密码，计数就清零。找回密码（安全问题）和后台登录不受这套阶梯影响。

## 注册

点「立即注册」进入注册表单，需要填四项：用户名、密码、安全问题、安全答案。

**安全问题是找回密码的唯一凭据**，请认真对待：

- 在安全问题字段按 `Enter` 可以从五个预置问题里选一个，也可以直接输入自己的问题。
- 答案大小写和多余空格不影响校验（`Blue Harbor` 和 `blue  harbor` 等价）。
- 答案是**唯一**找回账号的途径。忘记密码且忘记答案，账号里的数据只能由服务端管理员用 `-reset-password` 命令重置密码恢复。
- `Esc` 返回登录面板，已填的用户名会保留。

## 找回密码

点「忘记密码」进入三步向导，每一步标题下方都会显示当前是第几步：

1. **输入用户名** —— 服务端返回该账号的安全问题。
2. **回答问题** —— 答案正确则获得一个 5 分钟有效、只能用一次的重置凭据。
3. **设置新密码** —— 输入两次，一致后提交。

几个行为：

- 每次按 `Esc` 退回上一步，已填内容保留；在第一步按 `Esc` 返回登录面板。
- 两次密码不一致会就地提示，不会发出请求。
- 重置令牌过期（超过 5 分钟）时向导会退回第一步，需要重新开始。
- **重置成功后，该账号所有已登录的客户端会被强制登出**（令牌全部吊销），这是有意为之。
- 用户名不存在或该账号没有设置安全问题，都会显示"该账号无法找回"——服务端不区分这两种情况，以免暴露账号是否存在。

## 安全边界

安全问题是"知道即可重置"的凭据，强度取决于答案本身。服务端做了这些防护：

- 答案同样用 Argon2id 加盐哈希存储，数据文件泄露不等于答案泄露。
- 错误答案与错误密码共用同一套限流与退避。
- 重置令牌 5 分钟过期、一次性、只能用于改密码（不能当会话令牌用）。
- 重置后吊销该账号全部会话。

它防不住的是：知道答案的人同样能重置你的密码。如果这个风险不可接受，请不要在安全答案里写公开信息（比如出生城市或母亲娘家姓这类容易查到的）。

## 配置文件

默认位置：`%APPDATA%\link-chat\config.json`（Windows）或 `~/.config/link-chat/config.json`（Linux/macOS）。文件权限为 0600，因为里面有账号名。

```json
{
  "server": "wss://chat.example.com/ws",
  "username": "alice",
  "user_id": "u_…",
  "instance": "alice",
  "remember_session": true,
  "accounts": ["alice", "bob"],
  "account_settings": {
    "alice": {"theme": "paper", "language": "zh", "bubble_width": "70", "…": "…"},
    "bob":   {"theme": "ink",   "language": "en", "bubble_width": "80", "…": "…"}
  },
  "theme": "paper",
  "language": "zh",
  "motion_off": false,
  "bubble_width": 70
}
```

`server`、`remember_session`、`accounts`（最近登录过的账号名）是**本机设置**，只在这台电脑上有效。`account_settings` 是每个账号设置的**本机缓存**，真正的设置保存在服务器上，见下文「设置跟着账号走」。顶层的 `theme`、`language`、`bubble_width` 等字段是当前生效的设置，留着是为了退回旧版本客户端时仍能读到最后的设置；不必手动编辑。省略或写了不认识的值时按默认处理，不影响启动。

**配置文件里没有令牌。** 会话凭据存在操作系统的凭据库里：

| 平台 | 位置 |
|---|---|
| Windows | 凭据管理器，服务名 `link-chat`，用户名是「实例名/账号名」 |
| macOS | 钥匙串，同上 |
| Linux | Secret Service（GNOME Keyring / KWallet） |

拷贝这个配置文件到别的机器没有用，里面没有可用的凭据。设置界面「凭据存储」一行会显示当前用的是系统凭据库还是本地文件（无凭据库时的降级方案，文件权限 0600）。

**记住登录**（设置里可切换）：开启时下次启动在登录面板按一次 `Enter` 即可进入主界面；关闭时会立刻删除已存储的凭据，登录面板显示普通的密码输入框，之后每次启动都要输密码。升级到本版本时，旧配置文件里的令牌会自动搬进凭据库并从文件里抹掉，不需要重新登录。

上图是列表展开时的样子（彩色终端里，两侧消息的边框是不同的颜色）。选中会话后列表折叠，聊天区占满整行，见下文「列表的折叠与展开」。

### 左侧的三块

左侧自上而下分三块：

- **私聊**：所有一对一对话，每个私聊的名字就是对方的用户名，名字前是对方的头像。
- **群聊**：所有频道。
- **底部入口**：**好友、发现、我**，固定在左侧最下面，不随会话列表滚动，会话再多也在同一个位置。有新的好友申请时「好友」旁边显示数量；有人赞了或评论了你时「发现」旁边显示数量，只是好友发了新动态时显示一个圆点。

私聊和群聊**各自**按最近活动排序：群聊里很热闹，不会把一条安静的私聊挤出顶部。每块标题下第一行是新建按钮：私聊块是「+ 发起私聊」，群聊块是「+ 新建频道」。它们和会话一样能用 `↑` `↓` 选中，选中时右边显示新建页（见下文），所以不记快捷键也能新建。某一块是空的时，标题和新建按钮仍然保留。筛选（`Alt+F`）同时作用于两块，筛选时新建按钮隐去，不会把底部入口筛掉。

用 `↑` `↓` 在这三块之间**连续**移动：从最后一个私聊往下进入第一个群聊，再往下依次到「好友」「发现」「我」；在「我」上再按 `↓` 回到最上面的「+ 发起私聊」，在最上面按 `↑` 回到「我」，循环移动。小标题和空块的提示行不能被选中，光标会直接跳过。

**光标移到哪，右边就显示什么**，不需要按 `Enter`：

- 移到**私聊或已加入的频道**：右边立刻显示这个会话的消息。光标在上面停留片刻（约 0.15 秒）后才算「看过」：未读数清零、补拉历史消息。按住 `↓` 快速扫过的会话不会被清掉未读，也不会发出请求。
- 移到**还没加入的频道**：右边只显示这个频道的**预览**——名称、简介、成员数、最近活动和「按 → 或 Enter 加入」的提示。光是看**不会加入**，频道里的人也不会看到「你加入了」。按 `→` 或 `Enter` 才真正加入并打开它。
- 移到**「+ 发起私聊」「+ 新建频道」**：右边显示新建页——标题、一句说明、对方用户名（或频道名）的输入框和「按 → 或 Enter 开始输入」。按 `→` 或 `Enter` 进入后和打开会话一样，列表折叠、标题飞到正上方，键盘在输入框里；输入名字按 `Enter` 创建，成功后直接打开新的私聊或频道，可以马上打字。`Esc` 或 `←` 回到列表。名字不对（用户不存在、频道已存在）时，错误显示在输入框下方，改了再按 `Enter` 即可。`Alt+O`、`Alt+N` 在任何地方都直接进入这两个页面的输入框，不再弹出对话框。
- 移到**好友、发现、我**：右边显示对应的页面。好友和发现见下文「朋友圈与主页」。

**「我」页面**上方是你的头像、昵称、`@用户名` 和性别 · 年龄 · 签名，下面是一列选项：**编辑资料、我的动态、设置、帮助、关于**，再隔一行是**切换账号、退出登录**。`↑` `↓` 选择，`Enter` 打开；从设置、帮助、关于、编辑资料里按 `Esc` 都回到「我」。

**切换时整页平移**：光标换到另一行时，右边不是直接刷新，而是旧页和新页像上下并排的两张图一起平移——往下移时新页从下方推上来，往上移时从上方推下来，约 0.2 秒。按住 `↓` 连续移动时，每次都从屏幕上当前的样子接着平移，不会排队。关闭动画后直接切换。

上下移动只是「看」，列表**不会折叠**。按 `→` 或 `Enter` 才把键盘交给右边，这时列表折叠、标题飞到正上方居中，和打开会话完全一样；`←`（或 `Esc`）回到列表并展开，光标仍在原来那一行。`Alt+S`、`Alt+H`、`Alt+P` 在任何焦点下都直接进入设置、帮助和发现页面；设置和帮助属于「我」，从那里按 `Esc` 回到「我」。

刚登录时右边是欢迎页，**不会自动显示任何会话**；动一下光标才开始显示。

**关于**显示应用名称、版本和一行简介。版本来自仓库根目录的 `VERSION` 文件，编译时打进程序，所以不论用 `make build` 还是直接 `go build`，看到的都是同一个版本号，也和服务端的版本一致。

窗口太矮放不下底部入口时，入口会先让位，保证会话列表优先可见。

### 选中项的光效

列表拥有焦点时，被选中的那一行（不管是会话还是底部入口）文字上会有一道**光带**自左向右扫过，和输入框提示、登录按钮用的是同一种动画，只是更窄更慢，像一道安静的反光而不是整行闪烁。

- 光带只改变**文字的亮度**，整行选中背景的范围和位置不变，文字不位移。
- 光标移到新的一行，光带从该行最左边重新开始。
- 焦点离开列表、打开了对话框、掉线或关闭动画时，光带停止，选中行只剩静态的整行背景。
- 终端没有颜色差异时，退化为一个下划线加粗的字符在文字上移动。

列表里的几个约定：

- **左侧竖线**标记当前打开的会话，**「·」**标记私聊。频道不加标记——大多数条目都是频道，标记多数派是噪音。
- **未读数字**在右侧，优先于时间显示。

### 消息区：左右分栏的气泡

对话按**谁说的**分在两侧：**别人的消息靠左，你自己的靠右**。每条消息被一个边框圈起来，两侧的边框是**不同的颜色**，所以不用读名字就能分清谁在说话。

- **气泡宽度跟着内容走。** 一句「好」就是一个小气泡；很长的消息不会撑满整行，宽度上限是消息区的 70%，超出的部分在气泡里按显示宽度折行，中文和 emoji 不会被拆开。
- **只有别人的消息带名字。** 名字写在这一组消息的第一个气泡上方；你自己的消息不显示你自己的名字。
- **同一个人的连续消息合并。** 2 分钟内同一个人连着发的几条，只在第一条上方写一次名字，气泡紧挨着排在同一侧；换人发言、或隔了超过 2 分钟，就开始新的一组，中间空一行。
- **发送时间写在气泡底边上。** 例如 `└ 19:21 ───┘`；消息被编辑过会写「已编辑」。时间在你自己的气泡里靠右，在别人的气泡里靠左，不会碰到边角。
- **时间居中、不画横线。** 对话开头、以及两条消息之间隔了超过 5 分钟时，会有一行居中的时间（当天只显示时分，更早的带日期），上下各留一行空白，**没有**横贯整行的分隔线。
- **系统事件**（有人加入、离开频道）是居中的弱化文字，不带边框；**已删除的消息**显示一行弱化的「消息已删除」，同样不带边框，也看不到原来的内容。
- 顶部的「到达会话开头」「加载更早的消息…」提示独占一行，不会盖住消息；窗口刚好放得下整段对话时，为了不把开头的时间挤出视野，这行提示会让位给内容。

终端的降级：

- **不支持框线字符**：边框改用 ASCII（`+ - |`），位置和折行不变。
- **单色终端**：两侧边框的颜色退化成两种灰度，同时对方的边框改用虚线（`┄ ┆`）、你自己的仍是实线，靠线型也能分辨。
- **窗口特别窄**（消息区不足 28 列）：去掉边框，文字直接排在两侧，仍按左右和颜色区分。

## 快捷键

**所有命令都用 `Alt` 组合键。** 这不是随意挑的：终端里可打印的字母属于输入框，任何把 `s` 当成快捷键的设计都会让"想打 s 却打开了设置"。`Alt` 是少数不与输入冲突的修饰键。

**登录后焦点在会话列表上，不会自动打开任何会话。** 用 `↑` `↓` 移到一个会话，右边就显示它；按 `→` 或 `Enter` 进入，焦点到输入框，这时就可以直接打字、回车发送。

### 区域切换

界面分左右两块：**左边是会话列表，右边是光标所在那一行对应的页面**（会话、频道预览、设置、帮助或关于）。方向键和屏幕位置一致：

| 键 | 作用 |
|---|---|
| `←` | 去**左边**（会话列表），同时把列表**展开**。已经在最左再按，什么都不发生。设置页有自己的层级，`←` 先在层级之间后退，到最左一层再回列表 |
| `→` | 进入**右边**的页面，同时把列表**折叠**；对还没加入的频道，这一步会加入它 |
| `Tab` / `Shift+Tab` | 在两块之间来回切换（这个会绕回，因为它表示"下一个"而不是方向）；同样带着折叠与展开 |

输入框里有文字时，`←` `→` 先移动光标：只有光标已经在最左（行首）时，再按 `←` 才会去列表并展开它。文字和光标位置都会保留，再按 `→` 就原样回来，不会丢任何东西。

### 列表的折叠与展开

**折叠跟着焦点走，只有这一条规则**：键盘在输入框里，列表就折叠起来，聊天区扩展到整行宽度；键盘回到列表，列表就展开。`Enter`、`→`、`Tab`、`Esc` 只是移动焦点的不同入口，折叠自己跟着变，不需要单独操作。

- **名字会飞。** 打开一个会话时，它的名字从列表里那一行飞到屏幕**正上方居中**的标题处；再按 `←` 展开，名字又飞回那一行。整个过程约 0.3 秒，列表变窄、聊天区变宽、名字移动用的是同一个进度，所以三者始终同步，不会错位。
- **飞行中名字只出现一次。** 不会在列表里和标题里各显示一份；落地之后由标题（或列表那一行）接手显示。
- **列表内容在变窄到一半之前就先消失**，避免一条只有几格宽的窄条里挤着被截断的字。
- **展开后光标回到当前会话那一行**，并保证它可见，这样名字有地方可落；如果当前会话被筛选条件隐藏了，光标保持原位。
- **随时可以反向。** 折叠到一半再按 `←`，是从当前位置转向，不会先跳回起点，总时长也不会叠加。动画不挡输入：过渡中按的键立刻生效。
- **上下移动光标不会折叠。** 只有把键盘交给右边（`→`、`Enter`、`Tab`、`Esc`）时才折叠。
- **打开的会话被删除时**（频道被服务端删掉），焦点回到列表、列表自动展开。
- 关闭动画（`Alt+M`）后折叠与展开一步到位，名字不飞；过渡中途关闭动画，会立即落定到终点。
- 窗口窄到单栏（低于 48 列）时没有「侧边」可折叠，列表和聊天各占一屏，`←` `→` 的方向含义不变。

聊天区的标题（会话名与成员数）和下面的话题**水平居中**：折叠后它们就在屏幕正上方中央；展开时在变窄的聊天区里同样居中，所以折叠与展开之间标题只是左右平移。标题太长放不下时，从聊天区左边开始显示。

焦点竖条 `▌` 总是紧贴在获得焦点的那块标题的左边一格：折叠时在居中的会话名左边，展开且焦点在列表时在列表标题左边。

### 看出键盘在哪

获得键盘的那一块有三个标志：

1. 标题左边有一根竖条 `▌`
2. 标题是亮青色，另一块的标题是灰色
3. 输入框获得焦点时会出现完整的边框

竖条是字符而不是颜色，所以在单色终端、灰度截图、色盲情况下依然看得见。

切换焦点时竖条会在 0.18 秒内从一块滑到另一块；连续快速按键时它会从当前位置转向，不会跳回起点。

### 输入框的光带

输入框为空并且有焦点时，提示文字 `type in a message`（中文界面是 `在这里输入消息…`）上会有一道高光自左向右扫过，类似早期 iPhone 的"滑动解锁"。文字本身不动，只是亮度在走：

- 光带约 1.5 秒扫完一遍，然后停约 0.9 秒再来一遍
- 一开始输入，提示立刻消失，光带随之停止
- 删光输入后提示和光带恢复
- 焦点离开输入框时光带停止，提示变成静态灰色

**颜色降级**：真彩色终端是平滑渐变；256 色终端量化为 5 级亮度；单色终端没有亮度差，改为一个下划线加粗的字符在文字上移动。

### 动画开关

`Alt+M`（或设置里的"动画"）一个开关控制所有动画。关闭后：焦点竖条瞬间到位、输入框和列表的光带不再出现，提示显示为静态灰色，选中行只剩静态背景，登录界面的点阵静止，登录成功也不播放入场动画。切换时正在进行的滑动会立即落定，不会停在半路。

动画只在需要时刷新屏幕（光带运行中、焦点正在滑动、列表正在折叠展开、入场动画播放中，或停在登录界面上），其余时间界面完全静止、零额外开销，通过 SSH 使用也不会拖慢。登录界面的点阵只用约每秒 10 帧的低刷新率。**注意列表有焦点时选中行的光带在运行，所以那时屏幕不算静止**；需要完全静止时，关闭动画，或把焦点放在已有草稿的输入框里。折叠展开进行中列表的光带会暂停，不会两种动画叠在一起。

### 设置

设置是一个和聊天区同样位置的页面，分左右两栏：**左栏是分类**，按块分组——「个人」（账号）、「界面」（外观、聊天）、「系统」（通用）——块之间有小标题和空行；**右栏是所选分类下的选项**和当前值。光标移到哪个分类，右栏就立刻显示它的选项。

层级之间用 `←` `→` 来回：

| 键 | 作用 |
|---|---|
| `↑` `↓` / `k` `j` | 在当前层级里移动，到两端后循环到另一端 |
| `→` / `Enter` | 进入下一层：分类 → 选项 → **选择模式** |
| `←` / `Esc` | 回到上一层；在分类栏上回到会话列表 |

**选择模式**：在一个选项上按 `→`，它的候选值像转盘一样在这一项的值的位置竖着排开：当前候选和这一项同一行，用**黄色加粗**高亮；上下各最多显示两个候选，颜色分三级——黄色、中灰、深灰。选中行上下各 **3 行**固定清空，不管有几个候选（只有两个选项的开关也一样），所以转盘和别的选项之间至少空一行。转盘打开时右栏里的其他内容（分类标题和还看得见的选项）变成暗灰色；左栏和页面标题不变，预览也不变暗。选项列表上方固定留 2 行、下方固定留 3 行，第一项和最后一项的转盘都放得下，所以进出选择模式时选项、标题和预览都**不移动**。`↑` `↓` 换候选，`Enter` 或 `→` 确认并保存，`←` 或 `Esc` 放弃、恢复原值；退出选择模式后其他选项重新出现，颜色恢复。只读的选项（当前用户、服务器、凭据存储）进不了选择模式。

**预览**：「外观」「聊天」「消息样式」三个分类有一个小的聊天预览，用的就是真正的消息区画法，放在右栏选项下方空白处的**正中间**。选择模式里转盘和预览同时显示，换候选时预览**立刻**按候选值重画，确认之前就能看到效果；放弃则恢复。窗口矮时预览会缩小，只显示对话的后半段（仍然有双方的气泡和一行时间）；再矮就不显示——「聊天」分类的预览在 80×27 起可见，有六项的「消息样式」在 80×30 起可见，更矮时省略。

**账号操作**：「切换账号」和「退出登录」在「我」页面最下面，不在设置里。「切换账号」直接打开账号列表，「退出登录」先弹出确认框。

语言、主题、动画在选择模式里**只改预览**，确认后整个界面才切换——这样上下挑选时界面不会来回闪。

聊天类的设置：

| 设置 | 可选值 | 默认 |
|---|---|---|
| 气泡最大宽度 | 60% / 70% / 80% | 70% |
| 消息密度 | 舒适 / 紧凑（紧凑时不同人的消息之间不留空行，时间行前后的空行保留） | 舒适 |
| 时间格式 | 24 小时 / 12 小时（「下午 8:26」，英文界面「8:26 PM」） | 24 小时 |

消息样式（「界面」下的单独分类，同样带预览）：

| 设置 | 可选值 | 默认 |
|---|---|---|
| 消息边框 | 显示 / 隐藏（隐藏时只显示文字，仍分左右、按一方的颜色着色） | 显示 |
| 消息时间 | 显示 / 隐藏（隐藏的是气泡底边上的时间；消息组之间的时间行保留） | 显示 |
| 我方文字颜色 / 对方文字颜色 | 默认 / 青 / 蓝 / 绿 / 琥珀 / 玫红 / 紫 | 默认（正文颜色） |
| 我方边框颜色 / 对方边框颜色 | 默认 / 青 / 蓝 / 绿 / 琥珀 / 玫红 / 紫 | 默认（主题给双方的颜色） |

几种颜色在深色和浅色主题下都看得清；单色终端没有颜色可用，会忽略颜色设置。

#### 设置跟着账号走

外观、聊天、消息样式、语言这些设置保存在**服务器**上，和账号绑定：在一台电脑上改了，换一台电脑登录同一账号就是同样的样子。

- **登录后自动下载**：登录成功（输密码或用已保存的登录都算）后，客户端在后台取回这个账号的设置并立即换上，不需要重新打开会话。
- **第一次登录**：服务器上还没有这个账号的设置时（比如刚升级），客户端把这台电脑上现在的设置上传过去，界面不会变。
- **登录之前**：登录舞台和账号列表用的是上次登录的那个账号在本机缓存的设置；从账号列表换到另一个账号时，下载之前就先换成那个账号的缓存，不会先闪一下上一个账号的样子。没登录过的账号用默认设置。
- **修改**：在设置页确认后，本机立即生效，同时上传。上传失败（比如断线）时修改照样保留，状态栏提示「已保存在本机，未能同步到服务器」，下次修改或下次登录时会重新对齐。在转盘里上下浏览、按 `Esc` 放弃都不会上传。
- **另一处同时在线**：同一账号的另一个连接改了设置，这边会立即跟着变；如果这边正开着转盘，会等确认或放弃之后再换。
- **连到旧版服务器**：服务器不支持设置同步时，设置只保存在本机，不提示任何错误。

**「记住登录」只在本机**，不会上传：它决定的是这台电脑要不要保存登录凭据。服务器地址、凭据存储方式、最近账号列表也一样。

## 行为说明

**草稿按会话保存。** 在一个会话里打到一半切走，再切回来内容还在。

**新消息不打断阅读。** 当你向上翻看历史时来了新消息，底部会出现「有新消息 · 按 Alt+End 跳到底部」的提示，但不会抢走你的位置。

**断线自动重连。** 状态栏会显示重连倒计时，输入框转为只读但保留草稿。重连成功后自动补拉断开期间的消息，不重不漏。

**登录过期。** 如果重连时令牌已失效，客户端会直接打开登录界面而不是无限重试。

**单会话登录。** 同一账号同一时刻只有一处能在线。**在登录面板按下 `Enter` 恢复登录也算一次登录**——如果你在另一台机器（或另一个窗口）上还开着这个账号，那么后登录的这一个会顶掉前面那个，反之亦然。仅仅启动客户端、停在登录面板上不按 `Enter`，不会顶掉任何人。在别处登录会顶掉原来那处：被顶掉的窗口会弹出「已在别处登录」，显示**登录地点**、时间与顶号方的客户端名，并说明如果不是本人应立即改密码。被顶掉的窗口不会自动重连（它的令牌已经作废），按 `Enter` 可以重新登录，按 `Esc` 退出。

**空闲不会掉线。** 客户端每 15 秒发一次心跳，即使长时间不操作、也不收发消息，连接也保持有效。

**发送失败。** 内容会退回输入框，并提示原因；`Ctrl+R` 可重试。

**窄窗口。** 终端宽度低于 48 列时切换为单栏，用 `Tab` 在列表与消息之间切换。

## 朋友圈与主页

### 好友

朋友圈只在**好友**之间可见，私聊也只能和好友发起。好友关系是双向的：一方申请，另一方同意。

左下角的「**好友**」入口打开好友页。页面顶部和朋友圈一样是一个切换条，分三格：**通讯录、好友申请、广场**，`←` `→` 或 `Tab` 循环切换，`Esc` 回到列表。有待处理的申请时，「好友」入口和「好友申请」格旁显示数量。

- **通讯录**：好友（显示在线 / 离线）、把你删掉的人（显示「已将你删除」）和拉黑的人。`Enter` 打开主页，`m` 发私聊，`d` 删除，`b` 拉黑，`u` 解除拉黑。
- **好友申请**：别人发来的申请，实时出现。`a` 同意，`x` 拒绝，`Enter` 先看对方主页。拒绝后对方仍可再申请。
- **广场**：第一行可以直接输入用户名，按 `Enter` 后填附言（可不填），再按 `Enter` 发送。下面列出所有打开了「出现在广场」的人，每人后面显示性别、年龄和个性签名（不公开的不显示）。选中某人按 `Enter` 打开 TA 的主页，在主页上加好友或拉黑。对方如果已经向你发过申请，你们直接成为好友。
- **出现在广场**：设置 → 账号 →「出现在广场」。打开或关闭后，所有人的广场立即更新。
- **删除好友**：对方的通讯录会把你显示为「已将你删除」，你们之间原有的私聊仍在，但再发消息会提示「需要先加对方为好友」。对方也可以按 `d` 把这一行清掉。
- **拉黑**：同时解除好友关系；被拉黑的人看不到你的主页和动态，也不能再向你申请。

**发起私聊**：「+ 发起私聊」页列出还没和你开过私聊的好友，`↑` `↓` 选择，`Enter` 开始。

### 朋友圈页面

按 `Alt+P`，或在左下角「发现」上按 `→`，进入朋友圈。页面顶部是一个两格的切换条：**动态、通知**，选中的一格高亮。`←` `→` 或 `Tab` 切换，循环——在最右一格再按 `→` 回到第一格。`Esc` 回到列表。`↑` `↓` 选择，选中的一项整块高亮。

**动态**是你自己和所有好友的动态，新的在上面，往下翻到底自动加载更早的。一条动态的评论超过三条时会收起：只显示前两条，第三行是「展开评论」，选中它按 `Enter` 展开；展开后最后一行是「收起评论」。

| 键 | 作用 |
|---|---|
| `Enter`（在「+ 发动态」上） | 写一条动态：`Shift+Enter` 换行，`Tab` 在「所有好友 / 仅自己」之间切换，`Enter` 发布，`Esc` 放弃 |
| `l` | 赞，或取消赞 |
| `c` | 评论这条动态 |
| `↓` 进入评论后按 `r` | 回复选中的评论 |
| `d` | 删除自己的动态，或选中评论时删除评论（自己的评论，或自己动态下的任何评论），按 `y` 确认 |
| `Enter` | 打开作者的主页；在「展开评论 / 收起评论」上展开或收起 |
| `p` | 打开自己的主页 |

动态最多 500 字，评论最多 200 字。

**谁能看到什么。** 动态只给作者本人和作者的好友看；「仅自己」的动态只有你自己能看到。动态下面的赞和评论，你只能看到**你的好友**留下的——和你不认识的人在同一条动态下评论，你们彼此看不到。动态作者能看到全部。

**通知**列出谁赞了你的动态、评论了你的动态、回复了你的评论（好友申请在好友页）。打开这个标签就算全部看过，左下角的数字随之清零。

### 主页

每个人有一个主页：头像、昵称、`@用户名`、注册日期、是不是好友，一行性别 · 年龄 · 个性签名（不公开的不显示），以及你能看到的 TA 的动态。从动态、通知、好友页或广场上按 `Enter` 打开，`Esc` 回到原来的页面。

- 别人的主页：资料下面有一排按钮——好友是「发消息」「拉黑」，不是好友是「加好友」「拉黑」。`←` `→` 选择，`Enter` 确定。也可以直接按 `m`、`a`、`b`。
- 自己的主页：`e` 编辑资料。`↑` `↓` 切换昵称、签名、头像、颜色、性别、年龄。头像只能是一个字符（字母、汉字或 emoji）；颜色和性别用 `←` `→` 选，性别可选「不公开」；年龄只能输数字，留空即不公开。上面的预览随输入变化，`Enter` 保存，`Esc` 放弃。

昵称只在朋友圈和主页显示；聊天里仍然显示用户名，避免有人用昵称冒充别人。没设置过头像时，头像是用户名的首字母，颜色由用户名决定。

### 禁言期间

被禁言时不能发动态、评论，也不能改资料；点赞、删除自己的内容、处理好友申请不受影响。

## 被封禁与被禁言

服务器的管理员可以封禁或禁言账号。客户端会这样表现：

**被封禁。** 在线时被封禁，客户端立即回到登录面板，错误行显示原因和解封时间，例如「已被封禁：刷屏（至 2026-11-20 10:00）」，永久封禁显示「永久」。此时：

- 不再自动重连：重试多少次结果都一样。
- 已保存的登录被清除（服务器已经让它失效），密码栏需要重新输入。
- 封禁期间再次登录，只要密码正确，面板就显示同样的原因和时间，用户名保留。密码错误时仍然只提示用户名或密码错误。
- 封禁到期后可以直接登录，不需要任何人操作。

**被禁言。** 禁言期间你可以登录、阅读、加入频道和删除自己的消息，但不能发送、编辑消息或创建频道。此时：

- 输入框变为只读，显示「禁言至 2026-11-20 10:00，草稿已保留」，永久禁言显示「已被禁言，草稿已保留」。输入框里已有的草稿保留不动，`Esc` 仍然可以回到会话列表。
- 发送时才得知被禁言（例如禁言发生在你断线期间）时，被退回的内容留在草稿里，输入框同样进入禁言状态。
- 管理员撤销禁言时，输入框立即恢复。自然到期时服务器不会推送通知，客户端按到期时间自行恢复，不需要重新登录。

管理员建的账号没有安全问题，忘记密码时「找回密码」会提示联系管理员，由管理员重置。

## 主题与外观

内置两套主题：`ink`（深色，默认）与 `paper`（浅色）。在设置里切换，立即生效并持久化。

终端能力会自动降级：

- 不支持 Unicode 制表符时，边框与分隔线改用 ASCII（`+ - |`）。
- 只支持 256 色时，颜色映射到最接近的可用色。
- 单色终端没有颜色差异：消息边框的两种颜色退化为两种灰度，同时对方的边框改用虚线，自己的仍是实线，靠线型也能分辨；表单输入框没有背景可显示，改用两端的边界字符标出范围。
- `TERM=dumb` 时不使用任何框线字符。

### 与聊天界面有关的色彩

除了正文、强调色等通用颜色，主题还提供两组专用颜色，`ink` 与 `paper` 各有一套：

| 用途 | 说明 |
|---|---|
| 自己的消息边框 | 圈住你自己发出的消息，靠右显示 |
| 他人的消息边框 | 圈住对方的消息，靠左显示；与自己的边框颜色不同 |
| 输入框背景 | 表单输入框平时的背景，铺满整个输入宽度 |
| 输入框聚焦背景 | 光标所在输入框的背景，比平时的更亮一档 |

两种消息边框的颜色保证互不相同，并且各自与消息区背景有足够的对比度；两种输入框背景也都与对话框底色不同，所以空输入框同样看得出范围。

中文与 emoji 的宽度按实际显示宽度计算，折行与对齐不会错位。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 提示「连不上 ws://…」 | 提示里的地址不对，或服务端没启动。检查端口与 `/ws` 路径 |
| 提示「服务端不可用」 | 连上了服务器，但请求中途失败（例如服务端重启）。稍后再按一次 `Enter` |
| 一直显示「连接中」 | 服务端在但 TLS 证书有问题；`wss://` 需要有效证书 |
| 反复断线重连 | 反向代理的读超时短于心跳周期，调大 `proxy_read_timeout`（见 `server.md`） |
| 两个客户端总是同一个账号 | 它们共用了 `default` 实例；分别用 `-as alice` / `-as bob` 启动。注意即使共用一个实例，第二处也会把第一处顶下线 |
| 按下 Enter 后另一处被顶下线 | 同一账号只允许一处在线，恢复登录会顶掉别处；只启动不按 Enter 不会顶号 |
| 打开后很快被顶下线 | 该账号在别处登录；如果确认不是本人，立即修改密码 |
| 弹出「已在别处登录」 | 该账号在另一处登录顶掉了本窗口；不是本人操作请立即改密码 |
| 每次都要求输密码 | 设置里「记住登录」被关掉了，或系统凭据库不可用（看「凭据存储」那一行） |
| 想彻底不保存凭据 | 设置里关闭「记住登录」，会立即删除已存储的凭据 |
| 按字母打不出来 / 字母触发了命令 | 旧版键位把字母当快捷键；当前版本命令都在 `Alt` 上，纯字母一律输入 |
| `Alt` 组合键没反应 | 部分终端把 `Alt` 当作 Esc 前缀发送；检查终端设置里的 "Alt/Meta 作为 Esc" 选项，或换用 Windows Terminal / iTerm2 |
| 中文或 emoji 错位 | 终端不是 UTF-8。Windows Terminal 默认正确；旧版 `cmd.exe` 建议改用 Windows Terminal |
| 登录一直失败但密码没错 | 可能触发了限流，等一分钟再试 |
| 提示「该账号无法找回」 | 用户名不对，或该账号是旧版本注册的、没有安全问题 |
| 找回时说重置链接过期 | 第二步到第三步超过 5 分钟，重新走一遍 |
| 掉线后消息没补回来 | 检查会话是否仍存在；频道被删除后无法补拉 |

## 支持的终端

Windows Terminal、iTerm2、macOS Terminal、VSCode 集成终端、tmux（建议开启 `set -g default-terminal "screen-256color"`）。

推荐至少 80×24。低于 48 列会进入紧凑模式。
