# link_chat 客户端

终端聊天客户端。主界面是会话列表与聊天区两栏：选中会话后列表折叠、聊天区占满整行，底部是输入框。

## 安装与启动

```bash
make build-client
./build/link-chat                               # 默认实例
./build/link-chat -as alice                     # 名为 alice 的实例
./build/link-chat -server ws://host:8100/ws     # 临时指定服务器
./build/link-chat -config ./my.json             # 直接指定配置文件
```

## 同一台机器上登录多个账号

每个实例有自己的凭据文件，所以开两个窗口就能登录两个账号：

```bash
./build/link-chat -as alice     # 终端 1
./build/link-chat -as bob       # 终端 2
```

实例名决定配置文件位置：

```
%APPDATA%\link-chat\instances\alice.json
%APPDATA%\link-chat\instances\bob.json
```

- 不传 `-as` 时实例名为 `default`，多个不带参数的客户端**共享**同一份凭据——第二个会直接沿用第一个的登录状态。这正是需要 `-as` 的原因。
- 实例名只能用字母、数字和 `_ - .`。
- 从旧版本升级时，若 `instances/default.json` 不存在而旧的 `config.json` 存在，会自动迁移一次，不需要重新登录。

每次启动都会先打开登录面板：用户名、密码、登录按钮，按钮下面是「忘记密码」和「立即注册」两个链接。已有保存的登录时，面板预填用户名、焦点落在登录按钮上，按一次 `Enter` 即可登录（见下文「已记住的登录」）。

**服务器地址不在登录面板里。** 它来自配置文件，默认 `ws://127.0.0.1:8100/ws`（本机）。要连别的服务器，按优先级从高到低：

1. 启动参数 `-server wss://chat.example.com/ws`
2. 配置文件里的 `server` 字段
3. 内置默认值

地址可以省略协议和路径：

| 你写的 | 实际连接 |
|---|---|
| `chat.example.com` | `ws://chat.example.com/ws` |
| `chat.example.com:8100` | `ws://chat.example.com:8100/ws` |
| `wss://chat.example.com/ws` | 原样使用 |

公网请用 `wss://`。

## 登录面板

```
┌─ 登录 ─────────────────────────────────────────┐
│                                                │
│   用户名  [ alice                          ]   │
│                                                │
│   密码    [ █                              ]   │
│                                                │
│                  ┌──────────┐                  │
│                  │   登录   │                  │
│                  └──────────┘                  │
│                                                │
│              忘记密码    立即注册              │
│   ws://127.0.0.1:8100/ws                       │
│   Tab 切换 · Enter 确认 · Esc 退出             │
└────────────────────────────────────────────────┘
```

上图是单色终端下的样子。彩色终端里，每个输入框是一整条背景色块，焦点所在的那一条更亮；单色终端没有背景色可用，就用两端的方括号标出输入框的范围。

**输入框始终铺满整个输入宽度，与内容长短无关。** 用户名只有两个字时，背景也和密码框一样宽、左右边界对齐；空的输入框同样看得出范围。内容比输入框更长时，显示末尾的部分（光标在那里），不会撑破边框。注册、找回密码、新建频道与私聊的输入框都是同样的外观。

标签和输入框在同一行。登录按钮是一个带边框的小方框，聚焦时边框和文字变为强调色，并有一道光带从左到右扫过文字；关闭动画、或终端不支持彩色时，光带会降级为静态颜色或单个移动的标记。

`Tab` / `Shift+Tab` 在五个元素之间循环（用户名、密码、登录按钮、忘记密码、立即注册），`Enter` 激活当前焦点。两个链接带下划线，聚焦时变为强调色。终端支持鼠标时也可以直接点击。

两个链接是左右并排的，所以焦点在其中一个上时，可以用 `←` / `→` 在它们之间切换；在最左或最右那个上继续往外按是空操作，不会绕到另一个，也不会离开这一行。`↑` / `↓` 仍然在整个面板里上下移动焦点，`Tab` 的循环顺序也没有变。在输入框和登录按钮上，`←` / `→` 不起作用。

**错误信息显示在密码框与登录按钮之间**，水平居中，用红色。这一行是常驻预留的：没有错误时是空行，所以错误出现或消失时，面板的高度和按钮、链接的位置都不会跳动。太长的错误会在行尾截断，而不是换行。「正在连接」和正在使用的服务器地址仍然显示在面板底部的状态行里。

### 已记住的登录

有保存的登录时，用户名已预填，焦点直接落在登录按钮上；密码那一行**仍然是一个和普通密码一样宽的输入框**，里面是固定数量的圆点，没有文字，也没有光标。

这些圆点只表示「这里有已保存的登录」，**数量是固定的，和你真实密码的长度无关**（客户端本来也不知道密码），所以不会泄露长度。密码框保持原样而不是换成一句提示，是为了让面板在「已记住」与「普通」两种状态之间切换时形状不变、不跳动。

不需要输入任何东西，按一次 `Enter` 即可登录；底部常驻的提示行里有「Enter 确认」。一旦你在密码框里输入字符，圆点就会清空，面板恢复成普通的密码输入。

**为什么启动后还要按一次 Enter？** 同一账号同一时刻只有一处能在线，恢复登录会把别处的登录顶下线。如果启动时自动恢复，你只是「打开了程序」就可能把另一台机器上正在用的会话踢掉。所以现在启动本身不会登录，是否登录由你按下按钮决定。

以下任一情况会放弃已保存的登录，面板回到普通的密码登录（保存的凭据本身不会因此被删除）：

- 修改用户名（保存的登录属于特定账号）；
- 往密码栏输入或删除字符；
- 保存的登录已失效（过期、被吊销、或在别处被顶掉）：此时凭据会被清除，面板显示原因，光标移到密码栏。

如果只是网络不通或服务端没起来，**不会**清除保存的登录，直接再按一次 `Enter` 重试即可。

正在使用的服务器地址以灰色显示在面板底部的状态行里（它来自配置，不是一个可输入的字段），这样出错时你能分辨是地址写错了还是服务没起来。

## 注册

点「立即注册」进入注册表单，需要填四项：用户名、密码、安全问题、安全答案。

**安全问题是找回密码的唯一凭据**，请认真对待：

- 在安全问题字段按 `Enter` 可以从五个预置问题里选一个，也可以直接输入自己的问题。
- 答案大小写和多余空格不影响校验（`Blue Harbor` 和 `blue  harbor` 等价）。
- 答案是**唯一**找回账号的途径。忘记密码且忘记答案，账号里的数据只能由服务端管理员直接改 `users.json` 恢复。
- `Esc` 返回登录面板，已填的用户名会保留。

## 找回密码

点「忘记密码」进入三步向导，每一步标题下方都会显示当前是第几步：

1. **输入用户名** —— 服务端返回该账号的安全问题。
2. **回答问题** —— 答案正确则获得一个 5 分钟有效、只能用一次的重置凭据。
3. **设置新密码** —— 输入两次，一致后提交。

几个行为：

- 每次按 `Esc` 退回上一步，已填内容保留；在第一步按 `Esc` 返回登录面板。
- 两次密码不一致会就地提示，不会发出请求。
- 重置令牌过期（超过 5 分钟）时向导会退回第一步，需要重新开始。
- **重置成功后，该账号所有已登录的客户端会被强制登出**（令牌全部吊销），这是有意为之。
- 用户名不存在或该账号没有设置安全问题，都会显示"该账号无法找回"——服务端不区分这两种情况，以免暴露账号是否存在。

## 安全边界

安全问题是"知道即可重置"的凭据，强度取决于答案本身。服务端做了这些防护：

- 答案同样用 Argon2id 加盐哈希存储，数据文件泄露不等于答案泄露。
- 错误答案与错误密码共用同一套限流与退避。
- 重置令牌 5 分钟过期、一次性、只能用于改密码（不能当会话令牌用）。
- 重置后吊销该账号全部会话。

它防不住的是：知道答案的人同样能重置你的密码。如果这个风险不可接受，请不要在安全答案里写公开信息（比如出生城市或母亲娘家姓这类容易查到的）。

## 配置文件

默认位置：`%APPDATA%\link-chat\config.json`（Windows）或 `~/.config/link-chat/config.json`（Linux/macOS）。文件权限为 0600，因为里面保存了会话令牌。

```json
{
  "server": "wss://chat.example.com/ws",
  "username": "alice",
  "user_id": "u_…",
  "instance": "alice",
  "theme": "ink",
  "language": "zh",
  "motion_off": false,
  "remember_session": true
}
```

**配置文件里没有令牌。** 会话凭据存在操作系统的凭据库里：

| 平台 | 位置 |
|---|---|
| Windows | 凭据管理器，服务名 `link-chat`，用户名是实例名 |
| macOS | 钥匙串，同上 |
| Linux | Secret Service（GNOME Keyring / KWallet） |

拷贝这个配置文件到别的机器没有用，里面没有可用的凭据。设置界面「凭据存储」一行会显示当前用的是系统凭据库还是本地文件（无凭据库时的降级方案，文件权限 0600）。

**记住登录**（设置里可切换）：开启时下次启动在登录面板按一次 `Enter` 即可进入主界面；关闭时会立刻删除已存储的凭据，登录面板显示普通的密码输入框，之后每次启动都要输密码。升级到本版本时，旧配置文件里的令牌会自动搬进凭据库并从文件里抹掉，不需要重新登录。

### 左侧的三块

左侧自上而下分三块：

- **私聊**：所有一对一对话。
- **群聊**：所有频道。
- **底部入口**：**设置、帮助、关于**，固定在左侧最下面，不随会话列表滚动，会话再多也在同一个位置。

私聊和群聊**各自**按最近活动排序：群聊里很热闹，不会把一条安静的私聊挤出顶部。某一块是空的时，标题仍然保留，下面给一行提示怎么添加（`Alt+O` 发起私聊、`Alt+N` 新建频道）；没有任何会话时两块都是这样。筛选（`Alt+F`）同时作用于两块，不会把底部入口筛掉。

用 `↑` `↓` 在这三块之间**连续**移动：从最后一个私聊往下进入第一个群聊，再往下依次到「设置」「帮助」「关于」，到「关于」为止，不会绕回开头。小标题和空块的提示行不能被选中，光标会直接跳过。

选中底部入口按 `Enter`，打开对应的对话框；`Esc` 关闭后光标仍停在原来的入口上。`Alt+S`、`Alt+H` 在任何焦点下都能打开设置和帮助，与选中入口的效果一致。**关于**显示应用名称、版本和一行简介；用发行版构建时版本是真实版本号，自己从源码构建的显示 `dev`（构建时用 `make build VERSION=1.2.0` 注入）。

窗口太矮放不下底部入口时，入口会先让位，保证会话列表优先可见。

### 选中项的光效

列表拥有焦点时，被选中的那一行（不管是会话还是底部入口）文字上会有一道**光带**自左向右扫过，和输入框提示、登录按钮用的是同一种动画，只是更窄更慢，像一道安静的反光而不是整行闪烁。

- 光带只改变**文字的亮度**，整行选中背景的范围和位置不变，文字不位移。
- 光标移到新的一行，光带从该行最左边重新开始。
- 焦点离开列表、打开了对话框、掉线或关闭动画时，光带停止，选中行只剩静态的整行背景。
- 终端没有颜色差异时，退化为一个下划线加粗的字符在文字上移动。

列表里的几个约定：

- **左侧竖线**标记当前打开的会话，**「·」**标记私聊。频道不加标记——大多数条目都是频道，标记多数派是噪音。
- **未读数字**在右侧，优先于时间显示。

### 消息区：左右分栏的气泡

对话按**谁说的**分在两侧：**别人的消息靠左，你自己的靠右**。每条消息被一个边框圈起来，两侧的边框是**不同的颜色**，所以不用读名字就能分清谁在说话。

- **气泡宽度跟着内容走。** 一句「好」就是一个小气泡；很长的消息不会撑满整行，宽度上限是消息区的 70%，超出的部分在气泡里按显示宽度折行，中文和 emoji 不会被拆开。
- **只有别人的消息带名字。** 名字写在这一组消息的第一个气泡上方；你自己的消息不显示你自己的名字。
- **同一个人的连续消息合并。** 2 分钟内同一个人连着发的几条，只在第一条上方写一次名字，气泡紧挨着排在同一侧；换人发言、或隔了超过 2 分钟，就开始新的一组，中间空一行。
- **发送时间写在气泡底边上。** 例如 `└ 19:21 ───┘`；消息被编辑过会写「已编辑」。时间在你自己的气泡里靠右，在别人的气泡里靠左，不会碰到边角。
- **时间居中、不画横线。** 对话开头、以及两条消息之间隔了超过 5 分钟时，会有一行居中的时间（当天只显示时分，更早的带日期），上下各留一行空白，**没有**横贯整行的分隔线。
- **系统事件**（有人加入、离开频道）是居中的弱化文字，不带边框；**已删除的消息**显示一行弱化的「消息已删除」，同样不带边框，也看不到原来的内容。
- 顶部的「到达会话开头」「加载更早的消息…」提示独占一行，不会盖住消息；窗口刚好放得下整段对话时，为了不把开头的时间挤出视野，这行提示会让位给内容。

终端的降级：

- **不支持框线字符**：边框改用 ASCII（`+ - |`），位置和折行不变。
- **单色终端**：两侧边框的颜色退化成两种灰度，同时对方的边框改用虚线（`┄ ┆`）、你自己的仍是实线，靠线型也能分辨。
- **窗口特别窄**（消息区不足 28 列）：去掉边框，文字直接排在两侧，仍按左右和颜色区分。

## 快捷键

**所有命令都用 `Alt` 组合键。** 这不是随意挑的：终端里可打印的字母属于输入框，任何把 `s` 当成快捷键的设计都会让"想打 s 却打开了设置"。`Alt` 是少数不与输入冲突的修饰键。

**登录后焦点在会话列表上，不会自动打开任何会话。** 先选一个会话，按 `Enter` 打开，焦点才会进入输入框，这时就可以直接打字、回车发送，不需要再按 Tab 或点一下。

### 全局命令

| 键 | 作用 |
|---|---|
| `Alt+N` | 新建频道 |
| `Alt+O` | 发起私聊 |
| `Alt+S` | 打开设置 |
| `Alt+H` | 打开快捷键帮助 |
| `Alt+F` | 按名称筛选会话 |
| `Alt+↑` `Alt+↓` | 向上 / 向下翻阅历史消息 |
| `Alt+PgUp` `Alt+PgDn` | 整页翻阅 |
| `Alt+End` | 跳到底部 |
| `Alt+T` | 切换中英文 |
| `Alt+M` | 开关动画 |
| `Alt+Q` | 退出 |
| `Ctrl+C` | 退出 |
| `Esc` | 返回 / 关闭对话框 |

以上命令在任意焦点下都可用。

### 区域切换

界面分左右两块：**左边是会话列表，右边是聊天与输入框**。方向键和屏幕位置一致：

| 键 | 作用 |
|---|---|
| `←` | 去**左边**（会话列表），同时把列表**展开**。已经在最左再按，什么都不发生 |
| `→` | 去**右边**（输入框），同时把列表**折叠**；没有打开的会话时什么都不发生 |
| `Tab` / `Shift+Tab` | 在两块之间来回切换（这个会绕回，因为它表示"下一个"而不是方向）；同样带着折叠与展开 |

输入框里有文字时，`←` `→` 先移动光标：只有光标已经在最左（行首）时，再按 `←` 才会去列表并展开它。文字和光标位置都会保留，再按 `→` 就原样回来，不会丢任何东西。

### 列表的折叠与展开

**折叠跟着焦点走，只有这一条规则**：键盘在输入框里，列表就折叠起来，聊天区扩展到整行宽度；键盘回到列表，列表就展开。`Enter`、`→`、`Tab`、`Esc` 只是移动焦点的不同入口，折叠自己跟着变，不需要单独操作。

- **名字会飞。** 打开一个会话时，它的名字从列表里那一行飞到聊天区的左上角；再按 `←` 展开，名字又飞回那一行。整个过程约 0.3 秒，列表变窄、聊天区变宽、名字移动用的是同一个进度，所以三者始终同步，不会错位。
- **飞行中名字只出现一次。** 不会在列表里和标题里各显示一份；落地之后由标题（或列表那一行）接手显示。
- **列表内容在变窄到一半之前就先消失**，避免一条只有几格宽的窄条里挤着被截断的字。
- **展开后光标回到当前会话那一行**，并保证它可见，这样名字有地方可落；如果当前会话被筛选条件隐藏了，光标保持原位。
- **随时可以反向。** 折叠到一半再按 `←`，是从当前位置转向，不会先跳回起点，总时长也不会叠加。动画不挡输入：过渡中按的键立刻生效。
- **没有打开的会话时不会折叠。** 登录后的初始状态就是这样：输入框没有可输入的对象，所以 `→`、`Tab`、`Esc` 都不会把焦点送过去，列表保持展开；这样不会折出一个空白的整屏。
- **打开的会话被删除时**（频道被服务端删掉），焦点回到列表、列表自动展开。
- 关闭动画（`Alt+M`）后折叠与展开一步到位，名字不飞；过渡中途关闭动画，会立即落定到终点。
- 窗口窄到单栏（低于 48 列）时没有「侧边」可折叠，列表和聊天各占一屏，`←` `→` 的方向含义不变。

折叠状态下，焦点竖条 `▌` 在聊天区标题左边（最左的边距处）；展开时在列表标题左边。

### 看出键盘在哪

获得键盘的那一块有三个标志：

1. 标题左边有一根竖条 `▌`
2. 标题是亮青色，另一块的标题是灰色
3. 输入框获得焦点时会出现完整的边框

竖条是字符而不是颜色，所以在单色终端、灰度截图、色盲情况下依然看得见。

切换焦点时竖条会在 0.18 秒内从一块滑到另一块；连续快速按键时它会从当前位置转向，不会跳回起点。

### 输入框的光带

输入框为空并且有焦点时，提示文字 `type in a message`（中文界面是 `在这里输入消息…`）上会有一道高光自左向右扫过，类似早期 iPhone 的"滑动解锁"。文字本身不动，只是亮度在走：

- 光带约 1.5 秒扫完一遍，然后停约 0.9 秒再来一遍
- 一开始输入，提示立刻消失，光带随之停止
- 删光输入后提示和光带恢复
- 焦点离开输入框时光带停止，提示变成静态灰色

**颜色降级**：真彩色终端是平滑渐变；256 色终端量化为 5 级亮度；单色终端没有亮度差，改为一个下划线加粗的字符在文字上移动。

### 动画开关

`Alt+M`（或设置里的"动画"）一个开关控制所有动画。关闭后：焦点竖条瞬间到位、输入框和列表的光带不再出现，提示显示为静态灰色，选中行只剩静态背景。切换时正在进行的滑动会立即落定，不会停在半路。

动画只在需要时刷新屏幕（光带运行中、焦点正在滑动、或列表正在折叠展开），其余时间界面完全静止、零额外开销，通过 SSH 使用也不会拖慢。**注意列表有焦点时选中行的光带在运行，所以那时屏幕不算静止**；需要完全静止时，关闭动画，或把焦点放在已有草稿的输入框里。折叠展开进行中列表的光带会暂停，不会两种动画叠在一起。

## 行为说明

**草稿按会话保存。** 在一个会话里打到一半切走，再切回来内容还在。

**新消息不打断阅读。** 当你向上翻看历史时来了新消息，底部会出现「有新消息 · 按 Alt+End 跳到底部」的提示，但不会抢走你的位置。

**断线自动重连。** 状态栏会显示重连倒计时，输入框转为只读但保留草稿。重连成功后自动补拉断开期间的消息，不重不漏。

**登录过期。** 如果重连时令牌已失效，客户端会直接打开登录界面而不是无限重试。

**单会话登录。** 同一账号同一时刻只有一处能在线。**在登录面板按下 `Enter` 恢复登录也算一次登录**——如果你在另一台机器（或另一个窗口）上还开着这个账号，那么后登录的这一个会顶掉前面那个，反之亦然。仅仅启动客户端、停在登录面板上不按 `Enter`，不会顶掉任何人。在别处登录会顶掉原来那处：被顶掉的窗口会弹出「已在别处登录」，显示**登录地点**、时间与顶号方的客户端名，并说明如果不是本人应立即改密码。被顶掉的窗口不会自动重连（它的令牌已经作废），按 `Enter` 可以重新登录，按 `Esc` 退出。

**空闲不会掉线。** 客户端每 15 秒发一次心跳，即使长时间不操作、也不收发消息，连接也保持有效。

**发送失败。** 内容会退回输入框，并提示原因；`Ctrl+R` 可重试。

**窄窗口。** 终端宽度低于 48 列时切换为单栏，用 `Tab` 在列表与消息之间切换。

## 主题与外观

内置两套主题：`ink`（深色，默认）与 `paper`（浅色）。在设置里切换，立即生效并持久化。

终端能力会自动降级：

- 不支持 Unicode 制表符时，边框与分隔线改用 ASCII（`+ - |`）。
- 只支持 256 色时，颜色映射到最接近的可用色。
- 单色终端没有颜色差异：消息边框的两种颜色退化为两种灰度，同时对方的边框改用虚线，自己的仍是实线，靠线型也能分辨；表单输入框没有背景可显示，改用两端的边界字符标出范围。
- `TERM=dumb` 时不使用任何框线字符。

### 与聊天界面有关的色彩

除了正文、强调色等通用颜色，主题还提供两组专用颜色，`ink` 与 `paper` 各有一套：

| 用途 | 说明 |
|---|---|
| 自己的消息边框 | 圈住你自己发出的消息，靠右显示 |
| 他人的消息边框 | 圈住对方的消息，靠左显示；与自己的边框颜色不同 |
| 输入框背景 | 表单输入框平时的背景，铺满整个输入宽度 |
| 输入框聚焦背景 | 光标所在输入框的背景，比平时的更亮一档 |

两种消息边框的颜色保证互不相同，并且各自与消息区背景有足够的对比度；两种输入框背景也都与对话框底色不同，所以空输入框同样看得出范围。

中文与 emoji 的宽度按实际显示宽度计算，折行与对齐不会错位。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 提示「服务端不可用」 | 地址不对，或服务端没启动。检查端口与 `/ws` 路径 |
| 一直显示「连接中」 | 服务端在但 TLS 证书有问题；`wss://` 需要有效证书 |
| 反复断线重连 | 反向代理的读超时短于心跳周期，调大 `proxy_read_timeout`（见 `server.md`） |
| 两个客户端总是同一个账号 | 它们共用了 `default` 实例；分别用 `-as alice` / `-as bob` 启动。注意即使共用一个实例，第二处也会把第一处顶下线 |
| 按下 Enter 后另一处被顶下线 | 同一账号只允许一处在线，恢复登录会顶掉别处；只启动不按 Enter 不会顶号 |
| 打开后很快被顶下线 | 该账号在别处登录；如果确认不是本人，立即修改密码 |
| 弹出「已在别处登录」 | 该账号在另一处登录顶掉了本窗口；不是本人操作请立即改密码 |
| 每次都要求输密码 | 设置里「记住登录」被关掉了，或系统凭据库不可用（看「凭据存储」那一行） |
| 想彻底不保存凭据 | 设置里关闭「记住登录」，会立即删除已存储的凭据 |
| 按字母打不出来 / 字母触发了命令 | 旧版键位把字母当快捷键；当前版本命令都在 `Alt` 上，纯字母一律输入 |
| `Alt` 组合键没反应 | 部分终端把 `Alt` 当作 Esc 前缀发送；检查终端设置里的 "Alt/Meta 作为 Esc" 选项，或换用 Windows Terminal / iTerm2 |
| 中文或 emoji 错位 | 终端不是 UTF-8。Windows Terminal 默认正确；旧版 `cmd.exe` 建议改用 Windows Terminal |
| 登录一直失败但密码没错 | 可能触发了限流，等一分钟再试 |
| 提示「该账号无法找回」 | 用户名不对，或该账号是旧版本注册的、没有安全问题 |
| 找回时说重置链接过期 | 第二步到第三步超过 5 分钟，重新走一遍 |
| 掉线后消息没补回来 | 检查会话是否仍存在；频道被删除后无法补拉 |

## 支持的终端

Windows Terminal、iTerm2、macOS Terminal、VSCode 集成终端、tmux（建议开启 `set -g default-terminal "screen-256color"`）。

推荐至少 80×24。低于 48 列会进入紧凑模式。
