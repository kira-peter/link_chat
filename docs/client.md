# link_chat 客户端

终端聊天客户端。三栏布局：左边会话，右边消息流，底部输入框。

## 安装与启动

```bash
make build-client
./build/link-chat                               # 默认实例
./build/link-chat -as alice                     # 名为 alice 的实例
./build/link-chat -server ws://host:8100/ws     # 临时指定服务器
./build/link-chat -config ./my.json             # 直接指定配置文件
```

## 同一台机器上登录多个账号

每个实例有自己的凭据文件，所以开两个窗口就能登录两个账号：

```bash
./build/link-chat -as alice     # 终端 1
./build/link-chat -as bob       # 终端 2
```

实例名决定配置文件位置：

```
%APPDATA%\link-chat\instances\alice.json
%APPDATA%\link-chat\instances\bob.json
```

- 不传 `-as` 时实例名为 `default`，多个不带参数的客户端**共享**同一份凭据——第二个会直接沿用第一个的登录状态。这正是需要 `-as` 的原因。
- 实例名只能用字母、数字和 `_ - .`。
- 从旧版本升级时，若 `instances/default.json` 不存在而旧的 `config.json` 存在，会自动迁移一次，不需要重新登录。

首次启动会打开登录面板：用户名、密码、登录按钮，按钮下面是「忘记密码」和「立即注册」两个链接。

**服务器地址不在登录面板里。** 它来自配置文件，默认 `ws://127.0.0.1:8100/ws`（本机）。要连别的服务器，按优先级从高到低：

1. 启动参数 `-server wss://chat.example.com/ws`
2. 配置文件里的 `server` 字段
3. 内置默认值

地址可以省略协议和路径：

| 你写的 | 实际连接 |
|---|---|
| `chat.example.com` | `ws://chat.example.com/ws` |
| `chat.example.com:8100` | `ws://chat.example.com:8100/ws` |
| `wss://chat.example.com/ws` | 原样使用 |

公网请用 `wss://`。


`Tab` / `Shift+Tab` 在五个元素之间循环（用户名、密码、登录按钮、忘记密码、立即注册），`Enter` 激活当前焦点。两个链接带下划线，聚焦时变为强调色。终端支持鼠标时也可以直接点击。

服务器地址只在连接失败时以灰色显示在底部，这样你能分辨是地址错了还是服务没起来。

## 注册

点「立即注册」进入注册表单，需要填四项：用户名、密码、安全问题、安全答案。

**安全问题是找回密码的唯一凭据**，请认真对待：

- 在安全问题字段按 `Enter` 可以从五个预置问题里选一个，也可以直接输入自己的问题。
- 答案大小写和多余空格不影响校验（`Blue Harbor` 和 `blue  harbor` 等价）。
- 答案是**唯一**找回账号的途径。忘记密码且忘记答案，账号里的数据只能由服务端管理员直接改 `users.json` 恢复。
- `Esc` 返回登录面板，已填的用户名会保留。

## 找回密码

点「忘记密码」进入三步向导，每一步标题下方都会显示当前是第几步：

1. **输入用户名** —— 服务端返回该账号的安全问题。
2. **回答问题** —— 答案正确则获得一个 5 分钟有效、只能用一次的重置凭据。
3. **设置新密码** —— 输入两次，一致后提交。

几个行为：

- 每次按 `Esc` 退回上一步，已填内容保留；在第一步按 `Esc` 返回登录面板。
- 两次密码不一致会就地提示，不会发出请求。
- 重置令牌过期（超过 5 分钟）时向导会退回第一步，需要重新开始。
- **重置成功后，该账号所有已登录的客户端会被强制登出**（令牌全部吊销），这是有意为之。
- 用户名不存在或该账号没有设置安全问题，都会显示"该账号无法找回"——服务端不区分这两种情况，以免暴露账号是否存在。

## 安全边界

安全问题是"知道即可重置"的凭据，强度取决于答案本身。服务端做了这些防护：

- 答案同样用 Argon2id 加盐哈希存储，数据文件泄露不等于答案泄露。
- 错误答案与错误密码共用同一套限流与退避。
- 重置令牌 5 分钟过期、一次性、只能用于改密码（不能当会话令牌用）。
- 重置后吊销该账号全部会话。

它防不住的是：知道答案的人同样能重置你的密码。如果这个风险不可接受，请不要在安全答案里写公开信息（比如出生城市或母亲娘家姓这类容易查到的）。

## 配置文件

默认位置：`%APPDATA%\link-chat\config.json`（Windows）或 `~/.config/link-chat/config.json`（Linux/macOS）。文件权限为 0600，因为里面保存了会话令牌。

```json
{
  "server": "wss://chat.example.com/ws",
  "username": "alice",
  "user_id": "u_…",
  "instance": "alice",
  "theme": "ink",
  "language": "zh",
  "motion_off": false,
  "remember_session": true
}
```

**配置文件里没有令牌。** 会话凭据存在操作系统的凭据库里：

| 平台 | 位置 |
|---|---|
| Windows | 凭据管理器，服务名 `link-chat`，用户名是实例名 |
| macOS | 钥匙串，同上 |
| Linux | Secret Service（GNOME Keyring / KWallet） |

拷贝这个配置文件到别的机器没有用，里面没有可用的凭据。设置界面「凭据存储」一行会显示当前用的是系统凭据库还是本地文件（无凭据库时的降级方案，文件权限 0600）。

**记住登录**（设置里可切换）：开启时下次启动直接进入主界面；关闭时会立刻删除已存储的凭据，之后每次启动都要输密码。升级到本版本时，旧配置文件里的令牌会自动搬进凭据库并从文件里抹掉，不需要重新登录。

几个约定：

- 时间只在需要的地方出现：每段对话开头、时间跨度超过 5 分钟、或换人发言时。

## 快捷键

**所有命令都用 `Alt` 组合键。** 这不是随意挑的：终端里可打印的字母属于输入框，任何把 `s` 当成快捷键的设计都会让"想打 s 却打开了设置"。`Alt` 是少数不与输入冲突的修饰键。

输入框默认就是焦点——打开就能打字，回车直接发送，不需要先按 Tab 或点一下。

### 全局命令

| 键 | 作用 |
|---|---|
| `Alt+N` | 新建频道 |
| `Alt+O` | 发起私聊 |
| `Alt+S` | 打开设置 |
| `Alt+H` | 打开快捷键帮助 |
| `Alt+F` | 按名称筛选会话 |
| `Alt+↑` `Alt+↓` | 向上 / 向下翻阅历史消息 |
| `Alt+PgUp` `Alt+PgDn` | 整页翻阅 |
| `Alt+End` | 跳到底部 |
| `Alt+T` | 切换中英文 |
| `Alt+M` | 开关动画 |
| `Alt+Q` | 退出 |
| `Ctrl+C` | 退出 |
| `Esc` | 返回 / 关闭对话框 |

以上命令在任意焦点下都可用。

### 区域切换

界面分左右两块：**左边是会话列表，右边是聊天与输入框**。方向键和屏幕位置一致：

| 键 | 作用 |
|---|---|
| `←` | 去**左边**（会话列表）。已经在最左再按，什么都不发生 |
| `→` | 去**右边**（输入框）。已经在最右再按，什么都不发生 |
| `Tab` / `Shift+Tab` | 在两块之间来回切换（这个会绕回，因为它表示"下一个"而不是方向） |

输入框里有文字时，`←` `→` 先移动光标：只有光标已经在最左（行首）时，再按 `←` 才会去列表。文字和光标位置都会保留，再按 `→` 就原样回来，不会丢任何东西。

### 看出键盘在哪

获得键盘的那一块有三个标志：

1. 标题左边有一根竖条 `▌`
2. 标题是亮青色，另一块的标题是灰色
3. 输入框获得焦点时会出现完整的边框

竖条是字符而不是颜色，所以在单色终端、灰度截图、色盲情况下依然看得见。

切换焦点时竖条会在 0.18 秒内从一块滑到另一块；连续快速按键时它会从当前位置转向，不会跳回起点。

### 输入框的光带

输入框为空并且有焦点时，提示文字 `type in a message`（中文界面是 `在这里输入消息…`）上会有一道高光自左向右扫过，类似早期 iPhone 的"滑动解锁"。文字本身不动，只是亮度在走：

- 光带约 1.5 秒扫完一遍，然后停约 0.9 秒再来一遍
- 一开始输入，提示立刻消失，光带随之停止
- 删光输入后提示和光带恢复
- 焦点离开输入框时光带停止，提示变成静态灰色

**颜色降级**：真彩色终端是平滑渐变；256 色终端量化为 5 级亮度；单色终端没有亮度差，改为一个下划线加粗的字符在文字上移动。

### 动画开关

`Alt+M`（或设置里的"动画"）一个开关控制所有动画。关闭后：焦点竖条瞬间到位、光带不再出现，提示显示为静态灰色。切换时正在进行的滑动会立即落定，不会停在半路。

动画只在需要时刷新屏幕（光带运行中、或焦点正在滑动），其余时间界面完全静止、零额外开销，通过 SSH 使用也不会拖慢。

## 行为说明

**草稿按会话保存。** 在一个会话里打到一半切走，再切回来内容还在。

**新消息不打断阅读。** 当你向上翻看历史时来了新消息，底部会出现「有新消息 · 按 Alt+End 跳到底部」的提示，但不会抢走你的位置。

**断线自动重连。** 状态栏会显示重连倒计时，输入框转为只读但保留草稿。重连成功后自动补拉断开期间的消息，不重不漏。

**登录过期。** 如果重连时令牌已失效，客户端会直接打开登录界面而不是无限重试。

**单会话登录。** 同一账号同一时刻只有一处能在线。**启动时的自动登录也算一次登录**——如果你在另一台机器（或另一个窗口）上还开着这个账号，那么后启动的这一个会顶掉前面那个，反之亦然。在别处登录会顶掉原来那处：被顶掉的窗口会弹出「已在别处登录」，显示**登录地点**、时间与顶号方的客户端名，并说明如果不是本人应立即改密码。被顶掉的窗口不会自动重连（它的令牌已经作废），按 `Enter` 可以重新登录，按 `Esc` 退出。

**空闲不会掉线。** 客户端每 15 秒发一次心跳，即使长时间不操作、也不收发消息，连接也保持有效。

**发送失败。** 内容会退回输入框，并提示原因；`Ctrl+R` 可重试。

**窄窗口。** 终端宽度低于 48 列时切换为单栏，用 `Tab` 在列表与消息之间切换。

## 主题与外观

内置两套主题：`ink`（深色，默认）与 `paper`（浅色）。在设置里切换，立即生效并持久化。

终端能力会自动降级：

- 不支持 Unicode 制表符时，边框与分隔线改用 ASCII（`+ - |`）。
- 只支持 256 色时，颜色映射到最接近的可用色。
- `TERM=dumb` 时不使用任何框线字符。

中文与 emoji 的宽度按实际显示宽度计算，折行与对齐不会错位。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 提示「服务端不可用」 | 地址不对，或服务端没启动。检查端口与 `/ws` 路径 |
| 一直显示「连接中」 | 服务端在但 TLS 证书有问题；`wss://` 需要有效证书 |
| 反复断线重连 | 反向代理的读超时短于心跳周期，调大 `proxy_read_timeout`（见 `server.md`） |
| 两个客户端总是同一个账号 | 它们共用了 `default` 实例；分别用 `-as alice` / `-as bob` 启动。注意即使共用一个实例，第二处也会把第一处顶下线 |
| 打开就被顶下线 | 该账号在别处登录；如果确认不是本人，立即修改密码 |
| 弹出「已在别处登录」 | 该账号在另一处登录顶掉了本窗口；不是本人操作请立即改密码 |
| 每次都要求输密码 | 设置里「记住登录」被关掉了，或系统凭据库不可用（看「凭据存储」那一行） |
| 想彻底不保存凭据 | 设置里关闭「记住登录」，会立即删除已存储的凭据 |
| 按字母打不出来 / 字母触发了命令 | 旧版键位把字母当快捷键；当前版本命令都在 `Alt` 上，纯字母一律输入 |
| `Alt` 组合键没反应 | 部分终端把 `Alt` 当作 Esc 前缀发送；检查终端设置里的 "Alt/Meta 作为 Esc" 选项，或换用 Windows Terminal / iTerm2 |
| 中文或 emoji 错位 | 终端不是 UTF-8。Windows Terminal 默认正确；旧版 `cmd.exe` 建议改用 Windows Terminal |
| 登录一直失败但密码没错 | 可能触发了限流，等一分钟再试 |
| 提示「该账号无法找回」 | 用户名不对，或该账号是旧版本注册的、没有安全问题 |
| 找回时说重置链接过期 | 第二步到第三步超过 5 分钟，重新走一遍 |
| 掉线后消息没补回来 | 检查会话是否仍存在；频道被删除后无法补拉 |

## 支持的终端

Windows Terminal、iTerm2、macOS Terminal、VSCode 集成终端、tmux（建议开启 `set -g default-terminal "screen-256color"`）。

推荐至少 80×24。低于 48 列会进入紧凑模式。
